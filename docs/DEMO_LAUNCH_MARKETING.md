## 二、發布頁內容草稿（給 Ray 改）

**標題**：【試玩版】聖約第四騎士團 Saint Install —— EOS《永恆的原罪》世界的手機動作 RPG

**短介（一兩句，用在看板分享、Penana 公告）**
> 《永恆的原罪》的世界，第一次能親手玩。照順序點盤面上的數字開火、看準敵人出手的瞬間反擊，撐不住的時候——聖徒化。試玩版開放中，手機、電腦都能直接玩。

**長介**
> 聖約第四騎士團，在銀月高掛西天的大陸上，與禍魘與聖徒的殘骸作戰。
> （這裡放 Ray 的世界觀段落：EOS 讀者熟悉的名詞、角色、時間點——試玩版的故事在 EOS 時間線的哪裡。）

**玩法**
- 舒爾特盤戰鬥：盤面上的數字照 1、2、3… 的順序點，每一次命中都會對敵人開火；越快越準，傷害越高。
- 防禦與反擊：敵人出手前會出現光圈，光圈縮得越小再點，反擊越痛。
- 聖徒化：搭檔與你一起爆發，限時內打出大量傷害——但受擊會加速熔斷。
- 飛行與探索：駕船在大陸上空航行，降落城鎮探索、接劇情。

**試玩範圍**：序章起，到北方泊地、與索菈娜一戰為止（約 X 小時，待 Ray 實測填）。

**裝置與安裝**
- **電腦／Android／iPhone 都可以直接玩網頁版**：https://tivot-demo.pages.dev/ （建議直式、開聲音）
- **iPhone 想像 App 一樣用**：用 Safari 打開 → 分享 →「加入主畫面」→ 從主畫面圖示開啟；在主畫面的遊戲裡按首頁「離線下載」，之後斷網也能玩（約 1.5 GB，下載時不要鎖螢幕）。
- **Android 安裝版（APK）**：到 itch 頁下載（約 800 MB）→ 在手機上開啟 → 依提示允許「安裝未知來源的應用程式」。

**已知問題**（發布前由 Ray／PM 更新）
- 首次載入與每次換場景會有讀取時間（素材在雲端，第一次比較慢）。
- iPhone 的飛行畫面音效問題（HANDOFF 待查）——若發布前沒修好，寫在這裡。
- 試玩版存檔與正式版不保證相通。

**回饋**：請在本頁留言（遇到的問題、裝置型號、卡在哪一段），或填問卷（連結）。
