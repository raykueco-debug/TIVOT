# 主線後半大綱（Ray 口述，2026-09-27，ver -1786 時）

## 原文

森住民線完了之後是安雅主線
第四遺蹟攻略完成後米夏戰，強度做到玩家大概打不贏
然後就是長安雅線，主角方跟聖王廳翻臉，尼莫成為追兵，這邊才會有諾薇兒線，她的線主要綁尼莫跟賽西莉，她想幫助主角贏回賽西莉，但又因為覺得自己是學姐的替代品而痛苦

米夏終戰戰聖後，米夏暴走，尼莫亂入與主角共鬥擊敗米夏，米夏欲殺安雅取得雙子的另一半力量，被尼莫擊殺，安雅受到多重打擊又瞬間因米夏之死湧入力量暴走，安雅戰開打
安雅好感不足T4就會死，BE
戰勝安雅後，諾薇兒捨命的安撫使安雅力量壓了下來，代價是諾薇兒體內聖徒之力開始失控
第九星點亮，且全技能數值加倍，成為無敵的搭檔，但是每用一次都有可能觸發BE，諾薇兒被聖徒法環銷燬
因此進入諾薇兒線，回聖王廳找十二課的團長續命，但主角一行已被聖王廳通緝，因此聖王廳成為戰場。

## 章節順序（整理）

1. 森住民線（索菈娜，Stage 14 聖索菲亞 → 里朋莊園）
2. 安雅主線：第四遺蹟（埃爾王國廢城 `dunmor`）攻略完成 → **米夏戰（設計成大概打不贏）**
3. 長安雅線：與聖王廳翻臉、**尼莫成為追兵**；諾薇兒線在這裡埋線（尼莫／賽西莉、「學姐的替代品」）
4. 米夏終戰（戰聖）→ 米夏暴走 → 尼莫亂入共鬥 → 米夏被尼莫擊殺 → **安雅暴走、安雅戰**
   · 安雅好感 < T4 ⇒ **BE（安雅死亡）**
5. 戰勝安雅 → 諾薇兒捨命安撫 → 諾薇兒的聖徒之力失控
   · **諾薇兒第九星點亮、全技能數值加倍**；每用一次都可能觸發 **BE（諾薇兒被聖徒法環銷燬）**
6. 諾薇兒線：回聖王廳找十二課團長續命；主角一行已被通緝 ⇒ **聖王廳成為戰場**

## 與現有程式的接點（程式端註記，等那一段的稿來再做）

- **米夏戰「大概打不贏」**：劇情戰要寫 `allowLose:true` ＋ `onLose:'<label>'`（§6.5.2），輸了接著演、贏了走另一支台詞。
  ⚠ 要先定：打贏了劇情怎麼接（有沒有「打贏版」的台詞），否則 `allowLose` 的贏家路線會空掉。
- **安雅戰的 BE**：判定＝戰後看 `prog.tierOf(affection.anya) < 4`（T4＝好感 80）。
  BE 的收尾機制（結局畫面、回到哪裡）目前**還沒有**，docs/TIVOT_IMPL_SPEC.md 的 BE1~4 是規劃、沒實裝。
- **諾薇兒第九星**：-1774 起 ⑨ 是「條件星」，條件旗 `girlstar9_nouvelle`（`config.girls.starCond`）——
  **這一段就是那個條件**，由「諾薇兒捨命安撫」那一拍插。
  ⚠ 現行 ⑨ 終焉星的效果（聖徒化期間射擊延長爆發時間）要不要換成「全技能數值加倍＋每次使用有機率 BE」，等 Ray 定。
  「全技能數值加倍」的實作點＝`progress.girlBonus` 那一支（唯一查詢點）乘 2；「每用一次機率 BE」要新開一條。
- **安雅／索菈娜的 ⑨ 條件**：還沒定。
- **聖王廳成為戰場／通緝**：帝都（`capital`）與聖王廳會需要「通緝期」的版本（`storyStages` 窗、`rebuild` 那種整組換背景、禁航等），到時再看。
