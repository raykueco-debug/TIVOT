安雅的白襯衫與白裙、索拉娜的白腰布）。被線稿圍死的「封閉白袋」要能分出
**哪些是真背景**（髮絲之間、手臂與身體之間）、哪些是**衣服**。

| 判準 | 結果 |
|---|---|
| ① 亮度門檻（`mon_dekey` 原值 ≥251／std≤3.2） | ⛔ 蕾娜髮間留下一團團白塊 |
| ② 放寬到 ≥248 ＋ 環色一致性 | ⛔ 蕾娜好了，**諾薇兒的白袍胸口被挖穿** |
| ③ 亮度提到 ≥250.5 | ⛔ 諾薇兒好了，**安雅的白襯衫與白裙被挖穿** |
| ④ **與四角背景色的距離 ＋ 袋內平坦度 ＋ 環色一致性** | ✔ **四個角色一次全對** |

### ⚠⚠⚠ 為什麼亮度永遠做不到

量出來就知道：**兩邊的亮度是重疊的**。
· 蕾娜髮間的**真背景**白袋：平均 **250~253**（小袋被抗鋸齒拉低）
· 安雅白襯衫的**衣服**白袋：平均 **250.7~253.2**
**一條亮度線不可能把這兩組分開。** 換任何數字都只是在「誰被犧牲」之間搬家。

### ✔ 現行判準（三條都要成立才挖）

```
bgc   = 四角各 6px 的平均 RGB          # 這一張圖自己的背景色（實測 253.8~254.2）
① 與背景色的距離  max|袋平均RGB − bgc| <= 1.5     # 衣服的白有色偏，背景沒有
② 袋內平坦度      袋內像素 std        <= 2.0     # 衣服的白有漸層與筆觸
③ 環色一致性      環(4px) 的 RGB std  <= 26      # 髮間空隙四周全是頭髮；襯衫四周色雜
```

**實測分離度**（同一批圖）：
· 蕾娜髮間真背景：距離 **1.0 / 1.1 / 1.2 / 1.4**，袋 std 1.5~1.7 ⇒ 挖
· 安雅白襯衫　　：距離 **2.0 / 2.2 / 2.6 / 3.5 / 4.1 / 4.4**，袋 std 2.1~2.9 ⇒ 留
· 諾薇兒白袍　　：距離全部 > 1.5 ⇒ 全留（胸口不再挖穿）

⚠⚠ **`bgc` 要逐張現算，不可以寫死 255**：GPT 出的白底是 **253.8~254.2**，
寫死 255 會讓所有白袋的距離都超過門檻 ⇒ 一個都挖不掉。

⚠ 腳本住在 session 的 scratchpad（美術不動 `.py`，鐵律 11）。
**演算法與三個門檻都寫在上面了**，程式端要收成 `tools/si_dekey.py` 照抄即可
（骨架沿用 `tools/mon_dekey.py` 的 `label()` 與四邊灌水，只換白袋那一段的判準）。

### 驗收方法（每一批都要做）
把交件疊在**深色棋盤**上看 —— 髮間有沒有白塊、衣服有沒有被挖穿，一眼就知道。
⚠ 只看「透明像素百分比」看不出挖穿（安雅挖穿那一版是 57.9%，正常版也是 57.9%）。

## 六、**「只換頭」——（ver -1503 起）降級成「被擋死時的備案」**

> ⚠⚠⚠ **這一節已經不是主力作法了**（憲法 §5 ver -1503）：Ray 定案
> 「除了索拉娜以外都不用合成，索拉娜沒被擋也不要走合成，**保持 SI 多樣性**」——
> 合成回原圖＝身體永遠同一個姿勢。**四個人全部走全身重畫。**
> 以下內容原封不動留著：技術上它是成立的，**內容判定真的擋死時才動用**。

> Ray：「小心索拉娜被當作色情圖…目前解法是撞牆了 gem 跑再回 gpt alpha，
>   但是臉就常常會跑掉…有更好的解法可以提出。」

**有。這批差分全部是同一個姿勢（`front`），變的只有臉 ⇒ 那就不要讓它畫全身。**

| 步 | 做什麼 |
|---|---|
| ① | 從 `<角色>_SI_front.webp` **裁出頭部**（只有頭、髮、耳飾、領口），白底、放大 3× |
| ② | 上傳那張**頭部特寫**給 GPT，只要求「**同一個角色、同一個頭部角度與位置，只把表情改成 X**」 |
| ③ | **本機把新的頭合成回原圖**（羽化遮罩貼回同一個框，頸線與髮緣接得住） |

### 為什麼這是更好的解法（三件事一起解掉）

1. ⚠⚠⚠ **不會踩內容判定** —— 判定看的是**整張圖**，而頭部特寫沒有身體。
   **實測：索拉娜（舞者裝，全身必被擋）的頭部特寫一次就過，沒有任何拒絕訊息。**
2. ⚠⚠⚠ **臉不會跑掉** —— 參考圖就是**她自己的臉、全解析度**，而且產出只有頭，
   模型的全部注意力都在臉上。實測髮束走向、耳飾、領圈、瞳色、膚色全部守住。
3. ⚠⚠⚠ **服裝與畫風 100% 一致** —— 因為身體**根本沒有重畫**，是原圖的像素。
   ⇒ 這一條 `gem 跑再回 gpt alpha` 那條路永遠做不到（它每一趟都在重畫整張）。

### ⚠ 適用範圍與例外

· **只動臉的差分**（絕大多數）⇒ 走「只換頭」。
· **要動到手或身體的**（`point`／`wave`／`armcross`／`salute`／`holdfile`／`hug`／
  輪椅那兩張）⇒ 仍然要全身重畫。
  ⚠ 索拉娜的那幾張**先擱著**，等這一套穩了再想 —— 或者由 Ray 自己 SD＋PS。
· ⚠ 裁切框要**一個角色量一次就固定**，四張差分共用同一個框 ⇒ 合成回去天生對齊。
· ⚠ 合成用**羽化遮罩**（四邊漸退回原圖），不要硬貼；頸線那一側留寬一點。

### ⚠ 這一招連帶把另外三人也變便宜了

臉鎖死、服裝零漂移、圖更小（頭部 390×290 → 放大 3×）⇒ **四個人都走這一套**，
只有「要動手」的那幾張走全身。
