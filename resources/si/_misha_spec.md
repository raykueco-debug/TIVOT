## 二、⚠⚠⚠ 刀的比例 —— 量出來的，不要用形容詞

`chikushoudou.webp` 實測（逐欄厚度，護手那一格厚 203、刀身約 100）：

    柄頭 x=70 ── 護手 x=550 ── 鞘尖 x=1669
    柄 480 px ／ 刀身（連鞘）1119 px ／ 全長 1599 px

**⇒ 柄長 ＝ 刀身的 0.43 倍 ＝ 全長的 30%。雙手握得下。**

⚠⚠ **這就是 Ray 說「刀柄畫太短」的那個數字** —— 模型的預設是單手軍刀（柄佔全長
一成上下）。提示詞要把 **0.43／三成／雙手握得下**寫出來，**不要只寫「太刀」**
（同 §5「不要顆粒感要寫成改畫什麼」的同一個道理）。

**逐件鎖死**（每一張都帶）：

- **柄**：長，深色菱形交叉卷繩，末端一枚黃銅柄頭
- **護手**：黃銅 **D 形弓**（由柄頭掃到鍔）＋鍔上方一道 **S 形捲曲的鍔尖**
- **鞘／刀身**：長、緩弧、亮面黑漆
- ⛔ 不要畫成西洋軍刀的短柄、不要畫成沒有護手的日本太刀、不要加穗／刀緒

## 三、⚠⚠ 他不笑

**嘴角不上揚、不露齒、不畫臉紅、不畫汗滴、不畫閉眼笑。** 情緒靠**眉、眼神、下顎**
與**身體的角度**表達。⚠ 這一條要逐張寫進提示詞 —— 模型的預設會給男角「淡淡的微笑」。

## 四、這一批十張

| 鍵 | 演什麼 | 這一張的重點 |
|---|---|---|
| `stare` | 直視前方，眼神銳利 | 眼神 |
| `frown` | 蹙眉，明顯不悅 | 眉 |
| `talk` | 平靜地說話，嘴微張 | 嘴 |
| `order` | 右手抬起指向前方（下令） | **手臂完全伸直、明顯離開身體** |
| `guard` | 左手按在刀柄上，身體微側 | **手按在柄上、刀還在鞘裡** |
| `draw` | 拔刀，刀身出鞘約一半 | **柄的長度**＋出鞘的刀身 |
| `salute` | 軍禮，右手舉到額前 | 手到額 |
| `side` | 側身站，轉頭看向觀看者 | 身體轉四分之三 |
| `wound` | 負傷，左手按住側腹，上身前傾 | 身體的角度 |
| `close` | 閉眼、微微低頭 | 眼閉，**不是笑** |

## 五、產出規格

直式 **1024×1536**、**全身入框**、**alpha 背景（真正透明的 PNG）**、
無地面陰影、無文字、無邊框，四邊各留一點空白（§5：「有入框」不等於「留了餘裕」）。

### ⚠⚠⚠ alpha 一開始就要讓 GPT 生（Ray，2026-09-23）

> Ray：「**alpha 一開始就要讓 gpt 生，不要自己做。只有 gpt 打死生不出來的圖才自做 alpha**」

這一批我第一次跑成**白底**、打算本機 ToonOut —— **那是錯的**，憲法 §5（-1503）本來就寫著
「產圖時就把 alpha 要出來」。**本機 alpha（-1516 的 `si_matting.py`）是備案，不是預設。**

· 提示詞的產出規格那一行直接寫 **`alpha 背景（真正透明的 PNG，角色以外全部透明）`**
· 已經是白底的圖要補救，走憲法 §5 那句**格式轉換**的措辭（實測 6/6 成功、畫沒被重繪）：

```
100% 保留這張原圖，只把白色背景變成真正透明 Alpha PNG。
角色本身一個像素都不要改：同姿勢、同表情、同服裝配件、同線稿與上色、同構圖與尺寸。不要重新設計角色。
髮束之間、手臂與身體之間、服裝縫隙的空隙也要透明；邊緣不要白霧。角色身上本來就白的要保留。
```

⚠⚠ **轉完要比一次像素**（疊白底再與原圖比）：這一批 6 張是 **3.2~7.5**，
只有 `salute` 是 13.2 —— 並排看過，**不是重繪，是取景被稍微放大**。
⚠ **近白這條門檻對米夏天生偏嚴**（白髮＋白軍服）：這十張量到 11~18%，
但疊深底看**沒有白霧**。⇒ 看比例之前先疊深底用眼睛看。
