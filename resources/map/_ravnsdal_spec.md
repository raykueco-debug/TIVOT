# 拉芬斯達爾 Ravnsdal — 城市設計（北歐・1900）

> **城名（Ray 2026-09-12 交辦「取個 19 世紀北歐內陸風的名，不要跟現實城市撞名」）**
> **Ravnsdal ／ 拉芬斯達爾** —— 地圖 id `ravnsdal`、檔名前綴 `Ravn_`。
> · `ravn` ＝ 北歐語（丹麥／挪威）的**渡鴉**；`dal` ＝**谷** ⇒「渡鴉谷」。
> · `-dal` 是**內陸**地名的後綴（海邊會用 `-vik`／`-havn`／`-nes`）——
>   照 Ray 要的「內陸風」。⚠ 這座城其實是**港市**：名字留著它從谷地聚落長成港口的來歷，
>   那是可以用的設定，不是矛盾。
> · **撞名檢查**：查過沒有叫 Ravnsdal 的城鎮。相近但不同的是
>   Ravnkilde（丹麥，312 人的村）、Ravnsnæs（丹麥，584 人）、Ravnholm（哥本哈根北郊的一區）、
>   Ravnedalen（挪威 Kristiansand 的一座公園）—— 都不是城、也都不是這個拼法。
>   ⚠ 北歐的小地名多如牛毛，我只能保證「不撞到任何叫得出名字的城市」。

## 二、風格：**北歐・1900 年**

### ⛔⛔ 硬禁令（Ray 指定）

> 「**不要有任何旗幟跟國標**」

· ⛔ 不要旗子、不要旗桿、不要三角旗與串旗、不要船旗。
· ⛔ 不要國徽、市徽、盾徽、紋章、王冠、雙頭鷹、十字旗那一族。
· ⛔ 招牌上不要任何國家或官方的標誌 —— 商家招牌用**器物剪影**（鑰匙、麵包、酒桶、火槍）。
· ⚠ 行政廳也一樣：正面可以有大鐘與石雕花飾，但**不掛任何徽章**。

### ✅ 1900 年的北歐要畫什麼

| 要 | 怎麼畫 |
|---|---|
| **木造倉庫街** | 沿水邊一排排三四層的木造貨棧，山牆正對街、頂端有**吊貨的伸臂與滑輪**；外牆漆成赭紅、赭黃、暗綠，木板橫向密鋪 |
| **民族浪漫主義的石造建築** | 粗面花崗岩砌的底層、圓拱窗、厚重的塔樓與洋蔥／圓錐頂；線條沉穩、裝飾少 |
| **Jugendstil（新藝術）** | 只出現在比較新的臨街立面：帶曲線的窗框、鍛鐵陽台、植物紋的浮雕 |
| **屋頂** | 深色石板瓦或銅皮（生銅綠）；屋脊高陡（落雪用），老虎窗成排 |
| **街面** | 花崗岩方石鋪地、有車轍；鑄鐵**煤氣路燈**、繫馬環、排水溝 |
| **氣候** | 冷。空氣裡有海霧或煤煙，遠處被霧吃掉一階；屋簷與石縫有殘雪或水漬 |
| **1900 年的證據** | 電線與電報線橫過街道、早期的路面電車軌道（車可有可無）、玻璃櫥窗、鑄鐵柱廊 |

⛔ 不要：中世紀半木構（Fachwerk）、城牆與雉堞、南歐的赤陶瓦與拱廊、
現代玻璃帷幕、柏油、汽車、霓虹。
⛔ 絕對不要東方元素。

### 色調
低彩度的冷色：石灰白、花崗岩灰、赭紅木、銅綠、深藍灰的天。
暖色只從**窗內的燈光與煤氣燈**來 —— 那是這座城唯一的溫度。

## 三、留白：**只剩大教堂一格**（ver -1162，Ray 改定）

> Ray：「**大教堂留著，行政廳改成俯看全鎮的瞭望處，碼頭改成火車站**」

| 格 | 現況 |
|---|---|
| **大教堂 `church`** | ⬜ **仍然留白** —— 宗教建築的形制是世界觀的事 |
| ~~行政廳 `cityhall`~~ → **瞭望台 `lookout`** | ✔ 已定案，見 §四 |
| ~~碼頭 `dock`~~ → **火車站 `station`** | ✔ 已定案，見 §四 |

### ⚠⚠ 節點 id 跟著改了（`cityhall`→`lookout`／`dock`→`station`）

照抄帝都的**拓樸**（出口、樞紐與末端的分佈）一格不改，但**這兩格的內容
已經不是那個東西了** —— 留著 `dock` 當火車站的鑰匙，下一個讀這份資料的人
一定會以為那裡有船。這座城**還沒進 `script/town.js`**（實測 grep 是空的），
所以改 id 是零成本；`OUTING.nodesBy[城id]` 本來就是逐城一份，不受影響。

⚠ 這與聖索菲亞那條「不要順手統一 id」**不衝突**：那邊改的是**名字**
（`oldtown` 顯示成「舊街區」），這邊改的是**那一格是什麼**。

### ⚠ 「碼頭改成火車站」不影響出航

出航掛在 `square` 的**下方**（`sail`），本來就不是走 `dock` 那一格
（§6.5.4「城鎮入口的下方是出航」）。所以這一格換成火車站，
出航一行程式都不必動。
⚠ 順帶：這座城因此是**內陸感的港城** —— 廣場那一側仍有水面與繫纜柱
（飛空艇停泊處），貨運走鐵路。兩者不打架。

## 四、逐格美術簡報（**十一格**，留白的大教堂不在內）

左邊現在通瞭望台（上坡）、右邊通大教堂（**仍未定案**）—— 霧裡沒有承諾任何形狀，
所以大教堂之後定案時中心區**不必重畫**。

| **雜貨舖** `grocery` | 末端 | 底層的店：大片玻璃櫥窗，裡面堆著麻袋、罐頭、繩索、油燈與桶裝鹹魚；門口一台磅秤與幾隻木箱；招牌是一把鑰匙與一個桶的鐵剪影 |
