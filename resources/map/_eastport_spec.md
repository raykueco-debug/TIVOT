## 二、風格：**19 世紀地中海港都**

沿用俯視插畫已經定下來的樣子（`flight/city/_eastport_plan.md`）：
**密集的赤陶瓦舊城、窄巷網、碼頭邊一排倉庫、城緣的果園與菜畦。**

| 要 | 怎麼畫 |
|---|---|
| **牆與屋頂** | 石灰粉刷的牆（白、赭黃、淡赭紅，有斑駁與水痕）＋**赤陶筒瓦**的低斜屋頂 |
| **窗與陽台** | 木百葉窗（綠、藍灰），鍛鐵小陽台，窗台上有陶盆植物與晾著的衣物 |
| **街面** | 不規則的石板與碎石，窄巷有階梯；巷子上方橫著晾衣繩 |
| **港** | 石造碼頭與繫纜柱、吊貨的木製起重臂、堆著的木桶與麻袋、修補中的漁網 |
| **氣候** | 熱、乾、光很硬：**強烈的陽光與明確的陰影邊界**，牆面反光刺眼，陰影是冷藍紫 |
| **1900 年的證據** | 煤氣路燈、電報線、玻璃櫥窗、碼頭上的蒸汽起重機與軌道台車 |

⛔ **不要**：北歐的深色木造貨棧、雪與殘冰、哥德尖塔、
中世紀城牆與雉堞、現代柏油與汽車、霓虹。
⛔ **絕對不要東方元素。**
⚠ **旗幟／國標**：拉芬斯達爾那條硬禁令是**那座城的**（Ray ver -1161 指定），
這裡**沒有**同樣的指示 —— 但在 Ray 明講之前，**一樣不要畫國徽與國旗**，
招牌走器物剪影。要放就等他說。

### ⚠⚠ 船是水空二用、**著水靠岸**（ver -1163，世界觀設定）

- 停泊的船**浮在水上、繫在岸邊**：有吃水線與水面倒影，桅杆／浮空裝置在上。
  ⛔ **不要畫成離地懸停。**
- ⛔ 不要降落塔、繫留桅、跑道那一類空港元件。
- ⚠ 落點已經合規：東方泊地距最近水面 **2 格**（全圖最靠水的一座）。

### 色調
被曬白的石灰、赭紅瓦、海的深藍綠；陰影偏冷。
⚠ 與拉芬斯達爾**要看得出是兩個地方**：那邊是冷、低彩、暗；這邊是**亮、暖、對比硬**。

## 三、逐格美術簡報（十二格）

| 格 | 向數 | 這一格長什麼樣 |
|---|---|---|
| **港口廣場** `square` | 3（＋出航） | 城的入口：一塊被曬白的石板廣場，一側就是港灣的水面與繫纜柱，浮著繫好的船；中央一座**石砌的八角水池**（⛔ 不要人像、不要徽章）；三面是三四層的粉刷街屋，底層是拱廊店面；棕櫚或松樹幾株；地上有台車軌道 |
| **中心區** `midtown` | 3 | 全城最寬的一條街：兩側是粉刷與石造混合的四層街屋，底層拱廊；街心有行道樹與煤氣燈。⚠⚠ **左右兩條側街要往深處收窄、沒入強光的白**（左邊通海關署、右邊通主教座堂）—— 只看得到模糊的量體與一點暗，**不要畫出可辨識的塔或圓頂** |

| **海關署** `cityhall` | 末端 | 碼頭邊最體面的一棟：粗面石的底層、上兩層是拱窗與鍛鐵陽台，正面一排石柱與寬台階；門口堆著貼了封條的木箱與桶、幾個提著單據的人；⛔ 不掛任何徽章 |
| **舊城區** `oldtown` | **4** | 最老的一區：極窄的石板巷、兩側牆貼得很近，頭頂交錯著晾衣繩與電報線；牆上有拱形的小門與外露的石階；四個方向各一條走得進去的路（其中一條是往下的階梯巷） |
| **武器店** `gunstore` | 末端 | 拱廊底下的店面：厚重木門與鍛鐵門環，**櫥窗裡陳列著獵槍與彈帶**；招牌是一支火槍的鐵剪影（⛔ 沒有文字國標） |

## 六、程式端：**背景到齊才寫 `TOWNS.eastport`**

⚠⚠ 這一格**不是偷懶，是刻意的**：`bgFor` 在候選鏈全部載不到時是「照樣放行」——
畫面會**停在前一格的背景**，於是同一格從不同方向走進來會長得不一樣
（拉芬斯達爾的大教堂實測就是這樣，所以那一格改成暫時借中心區那張）。
12 格全缺就是整座城都這樣，那比「還不能降落」糟得多。

所以順序是：**背景交件 → 寫 `TOWNS.eastport`（照 §一那張表）→
`flight/index.html` 的 `SETTLEMENTS` 那一列補 `town:'eastport'` → 降落鈕自己會亮。**
⚠ 那一列已經有註解寫著這件事（`flight/index.html` 的東方泊地那一段）。
