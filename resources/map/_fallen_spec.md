## 一、拓樸：5 格・4 邊・**環數 0**（樹狀）

```
                 祭壇
                  │
   沉水石坑 ──── 傾石岔口        ← 唯一的岔口（三向）
                  │
                斷柱道
                  │
                崩塌門廊
                  │
               原野（跨圖）
```

| 節點 id | 中文 | 向數 | 出口 |
|---|---|---|---|
| `entry` | 崩塌門廊 | 2 | `up:'causeway'` ＋ 跨圖出口（後） |
| `causeway` | 斷柱道 | 2 | `{ up:'fork', back }` |
| `fork` | 傾石岔口 | **3** | `{ up:'altar', left:'basin', back }` |
| `basin` | 沉水石坑 | 端末 | `back` |
| `altar` | 祭壇 | 端末 | `back` |

- **一直按↑**：崩塌門廊 → 斷柱道 → 傾石岔口 → 祭壇（走到底就停，沒有同向繞圈）。
- ⚠ 過道與端末寫成 `{ up:<前進>, back:<退回> }`，**不要寫死 `down`**（憲法 §6.5.4 ver -903）——
  `back` 由 `exitsOf` 現算成來時方向的反向，這張圖之後接到別張時才不會被綁死成垂直主軸。
- ⚠ **入口那一格不可以有戰鬥**（§6.5.2）：`entry` 留空。
- ⚠ **結算怪**：只有一個跨圖出口＝末端型，ver -895「擺在沒走進來的那個出口」不適用，
  由資料指定即可（建議 `altar`）。
- ⚠ 迷霧預設是有的（ver -913），**不要**寫 `mist:0`。

## 二、畫風鐵則

### 1．坍倒石製 ＝ 只有素面的石頭

| ✅ 要 | ⛔ 不要 |
|---|---|
| 粗鑿的灰色巨石塊（石灰岩／花崗岩） | 金飾、鍍金、彩繪玻璃、壁畫、雕像 |
| 倒下的**圓柱鼓**、斷裂的過梁、風化的表面 | 任何精緻的雕飾或花紋 |
| 石縫裡的野草、苔、低矮灌木、被風吹歪的樹 | 文字銘刻（祭壇的幾何刻紋除外） |
| 碎石與裸土 | 東方元素（朱漆・斗拱・飛簷・琉璃瓦・龍鳳雲紋・燈籠） |

⚠⚠ **要與地宮（`Undercity_*`）明顯分開**：那邊是**被埋掉的華麗皇宮**（大理石、鍍金、
吊燈、彩色石片地板），這邊是**素面石頭、在戶外、被草長回去**。
兩者都叫「遺跡」，但如果這一組畫得太精緻，玩家會讀成同一個地方。

### 2．⚠⚠⚠ 全場景露天（Ray 指定）

**五張都要看得到天空**，沒有屋頂、沒有洞窟、沒有室內。
⇒ 連帶：**五格全部都有室外光，照「有室外光才有差分」那條，五格都要四時段差分**
（＝20 張）。這是這組最大的成本，要不要全做由 Ray 決定。

### 3．遼闊七招照舊
鏡頭壓低／地平線在下三分之一／近端用倒石或斷柱框住畫面／重複元素等距縮小／
深處放人影或缺口當尺度／光源放遠／不要塞滿。

## 三、逐格特徵

| 格 | 向數 | 這一格長什麼樣 |
|---|---|---|
| **崩塌門廊** | 入口 | 一道還立著的巨大石門框：兩根方形巨柱撐著一條**歪斜裂開的過梁**；兩側牆倒成碎石坡；**穿過門框看得到裡面的路**往深處去 |
| **斷柱道** | 通道 | 兩側各一排倒下的圓柱，斷成一節節的**圓柱鼓**像骨節排開；幾根只剩半截仍立著；中間一條筆直的土路往深處收斂 |
| **傾石岔口** | **三向** | 三塊**巨大的斜倚石板**互撐出一塊三角空地；⚠ 三個方向各一條**真的走得進去的路**（正前上坡／左邊下坡／畫面下緣是來路），開口大小相近、地面土路連續延伸進去 |
| **沉水石坑** | 端末 | 鋪石廣場**塌陷成淺坑**，坑底一窪水映著天；四周是崩落的階梯與傾斜鋪石；蘆葦與半泡在水裡的落石。四面被石牆與土坡圍死 |
| **祭壇** | 端末 | 路的盡頭：**粗鑿的整塊石台**，台面刻著**幾何刻紋**（同心圓／直線／三角，不是文字）；外圍一圈**未經雕琢的立石**（menhir），有的倒了；更外圈只剩一排**圓形柱基**；野草沿石縫長成一圈 |
