## 一、Ray 的三個硬條件

| 條件 | 怎麼落地 |
|---|---|
| **外觀已經破敗** | 主塔屋頂塌掉一半、露出木桁架與斷石肋；飛扶壁斷了兩三根只剩半截懸空；尖拱窗只剩空框、玻璃碎光；通往大門的橋斷了一截；牆面爬枯藤、石縫長出歪斜細樹 |
| **倚在懸崖前** | 堡體整個站在崖腳的岩台上、貼著崖面往上疊；⚠ **輪廓要與岩壁分得開**（清楚的深色描邊），不要糊成同一片灰 |
| ⚠⚠⚠ **古堡高處比崖高** | **崖頂稜線畫在畫面上方三分之一**，稜線以上就是天空；**主塔尖穿過那條稜線**，上半截整段襯在天空上 |

### ⚠⚠ 第一版是在這一條上失敗的

v1 的岩壁從頭到尾都高過城堡，塔尖後面還是岩石 —— 氣氛很好，但**最重要的那句話沒做到**。
⇒ 要求「A 比 B 高」時，**不能只寫「A 要比 B 高」**，要寫成**天際線的關係**：
「稜線落在畫面的哪裡」「稜線以上是什麼」「塔尖的哪一截襯在天空上」。

### ⚠ 第二個修正：要像「城堡」，不要像「主教座堂」

v1 畫成了一座大教堂（玫瑰窗＋中殿正面）。哥德式的垂直感與尖拱是對的，
但建築的性格要換：**方形主堡（keep）＋圓形角塔（尖錐頂）＋城牆與雉堞＋射孔**，
玫瑰窗**只留一扇**在主堡正面，其餘改成細長尖拱窗。

## 二、這一批的共同畫風（內景沿用）

- 石工：切割整齊的灰白石灰岩，砌縫清楚；破損處露出乾淨的斷面。
- 光：黃昏偏冷 —— 天空下緣一道橘、上方轉藍灰；建築大部分在陰影裡，
  只有塔尖與朝西那一面被打亮；窗洞裡透出一點冷白的光。
- 「大」的七招照舊：鏡頭壓低仰望／地平線放在下五分之一／近端用被切到的巨石框住一角／
  重複元素等距縮小／小燈火當尺度（⛔ 不要畫人）／光源放遠／天空留大片空白。
- 四鐵則：`anime style, cel shading, clean lineart，絕不要顆粒感、不要雜訊噪點、不要油畫質感`
  ＋ 平塗色塊、硬邊陰影、2~3 階、明確深色描邊、石面整塊平面、雲是有形狀的塊。
- ⛔ 絕對不要東方元素。

**顆粒**：0.67（校準點＝石製遺蹟被退的那批 0.88~1.74）。

## 五、外廓的四時段差分（ver -1160）

```
resources/background/Belisar_Exterior_{dawn,day,dusk,night}.webp
```
1536×1024、q85。顆粒 0.55~0.74（校準點＝石製遺蹟被退的那批 0.88~1.74）。

**產法**：`dusk` 是原本那張（Ray 拍板的構圖），其餘三張**以它為底衍生** ——
在同一串對話裡用「以**這一串最後那一張**為底，構圖／視角／焦距／景物位置與比例
完全不變，**只換光與色溫**」。
⚠ 這是唯一有效的參照方式：在長對話裡說「以第 N 張為底」**沒有用**，
ChatGPT 不會真的吃那張圖（墓門那一輪踩過，見 `_tomb_spec.md` §十二）。

實測四張的崖頂稜線、塔尖穿過稜線的位置、斷橋、近端巨石全部對得上。
`night` 那一張的提示詞有寫死「⚠⚠ 絕對不要把星星連成線、不要星座線、不要銀河帶」——
那是 Gemini 犯過、GPT 也會犯的錯。
