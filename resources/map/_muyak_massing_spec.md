## 一、⚠⚠⚠ 先講這張圖**量不出什麼**（§6.8.1 一.1，貝利薩爾的教訓）

**透視圖量不出平面位置。** 貝利薩爾那三版退稿（「這是 minecraft 嗎？太方了」
「還是太方」）的成因就是這個：外觀圖只給得出**顏色**與**正面的輪廓**，
平面（哪一塊在哪、翼怎麼歪出去、進深多少）一律是**估**的，而估出來的必然方正對稱。

| 這張外觀圖**給得出** | 這張外觀圖**給不出** |
|---|---|
| 天際線的節奏（幾支塔、高低怎麼錯開） | 每一塊的**平面位置與進深** |
| 各部位的**相對高度比** | 牆列是直的還是折的 |
| 開口的大小與位置（在立面上） | 獨立石柱在平面上散在哪裡 |
| 材質與顏色 | 整體的不對稱**在平面上**長什麼樣 |

⇒ **要平面就要另一張正俯視的高度圖**。交件 B 那張草稿是拿現有量體反算的，
**直接在上面改**（座標系、比例、灰階對應全部現成），改完就是量得出來的骨架。
⚠⚠ 那是**技術圖不是插畫**：§5 的四條畫風鐵則在那張上**不適用也不要套** ——
要的是精確的形狀與精確的灰階，不要光影、材質、描邊、透視。

## 二、這張外觀圖**讀得出來的四件事**

1. **它是一片建築群，不是一棟建築** —— 十幾支塔、柱與殘牆擠在一起，
   天際線像**一排斷掉的梳齒**。這是這座剪影的重點（與 -1222 的判讀一致）。
2. **高度差距很大**：最高的細柱約是最矮那截殘牆的**四到五倍**。
3. **由左到右逐段塌矮**：左端最高最完整 → 中段是連續的拱列與大拱門 →
   右端散成孤立的柱與倒下的柱鼓。
4. **沒有任何屋頂**，每一支塔都是斷頭、斷口不齊。

### ⚠ 與現有量體（ver -1221~-1226）不一樣的兩處

| | 現有量體 | 外觀圖 |
|---|---|---|
| 牆的頂緣 | 一律 `crenel`（雉堞、缺齒） | **沒有雉堞** —— 是**參差的斷口**（被啃過的斷牆，不是城垛） |
| 開口 | 少數幾個 `col` | **連續的拱列**（一整排大拱），而且**拱之間的墩子很細** |

⇒ 這兩件會明顯改變剪影。要照外觀圖改的話，`crenel` 那一組要換成
「每段牆自己的斷口高度不齊」，而拱列適合用**細墩＋大開口**排。

## 三、實測的顏色（給程式端對 `RUIN_PAL.mossgrey`）

石面（低彩度、中高明度、扣掉天空）平均 **RGB (172,173,167)**、
明度 p10/p50/p90 ＝ 125 / 177 / 206。

現行 `mossgrey` 是 `sideLit #b6bab2 (182,186,178)` / `side #949a92 (148,154,146)` /
`dark #5e645e (94,100,94)` —— **落在量到的範圍裡，不必改**。
貼材 `moss_stone`（ver -1224）的底色 (179,183,176) 也對得上。

## 四、提示詞裡「為了建模」而寫死的那幾條（日後要外觀圖照抄）

- **視角**：四分之三、鏡頭略高於地面、**幾乎正面平視**；⛔ 仰角／俯瞰／魚眼。
  （仰角就是貝利薩爾那張量不出平面的原因。）
- **整座完整入框、四邊各留 10%**；⛔ 被畫面切掉。
- **前景不要有東西擋住輪廓**（樹枝、草叢、岩石）—— 擋住就量不出剪影。
- **地面線要清楚**：看得出每一段是從地面哪一點長出來的。
- **照明均勻**（陰天散射光）；⛔ 逆光剪影、⛔ 強烈長投影、⛔ 霧遮住它。
- ⛔ **不要畫在飛行距離讀不出來的細節**（§6.8.1 四.3）：一整排細尖拱窗、小龕、
  浮雕、雕像、碑文。牆面的節奏用**扶壁與大開口**表達。
- **山的稜線要比最高的塔還高** —— 「藏在山坳裡」是寫成**天際線關係**的，
  不是形容詞（同貝利薩爾「古堡高處比崖高」那條的反面用法）。
