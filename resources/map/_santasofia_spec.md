## 二、畫風鐵則

### 1．西班牙風＝要畫出這些

| ✅ 要 | ⛔ 不要 |
|---|---|
| 白灰泥牆（cal）與赭黃石、剝落露磚 | 任何東方元素（朱漆・斗拱・藻井・飛簷・琉璃瓦・龍鳳雲紋・燈籠・屏風・和式格柵・漢字） |
| 赤陶瓦屋頂（teja）、連續拱廊（soportales） | 北歐尖屋頂、木構半木造（Fachwerk） |
| 鍛鐵陽台與壁燈（reja / farol）、垂下的紅色天竺葵 | 玻璃帷幕、任何工業感的金屬 |
| 彩繪瓷磚 azulejo（藍白）鑲門框與踢腳 | 馬賽克鋪成的現代圖案 |
| 圓卵石路、幾何鋪石廣場 | 柏油、水泥 |
| 橙樹、棕櫚、內庭 patio 與噴泉 | 針葉林、竹 |
| 摩爾式**馬蹄拱**與木格窗（Mudéjar 的殘留） | —— |
| 石造鐘塔、plateresco 雕飾、歐式石獅 | —— |

⚠ **Mudéjar／摩爾元素不算「東方元素」** —— 憲法 §5 那條禁的是**中日**風
（朱漆斗拱那一族）。馬蹄拱與幾何木格窗是西班牙建築自己的一部分，要留。

### 2．四鐵則照舊（§5）
每一則提示詞結尾都帶完整那一句：
`anime style, cel shading, clean lineart，絕不要顆粒感、不要雜訊噪點、不要油畫質感`。

### 3．遼闊七招照舊（同地宮那一份）
鏡頭壓低／三段深度／重複元素等距縮小／人影當尺度／光源放遠／不要塞滿／上下留空。

### ⚠⚠ 這一批踩到的坑（收圖用）

1. **chatgpt.com 的下載在這台 Chrome 被擋**：程式觸發的 `a.click()` 完全不作動
   （同一支程式在 gemini.google.com 就會下載）。**只有真的滑鼠點擊會過**，
   而真點擊需要 **Chrome 視窗是系統前景視窗**。
2. **CSP 擋掉本機 HTTP**：`fetch('http://127.0.0.1:…')` 在 chatgpt.com 與
   gemini.google.com 都是 `Failed to fetch`，所以「把 bytes POST 回本機」這條路不通。
3. ⇒ **收圖一律走「聯絡表＋一次真點擊」**：頁面內把多張圖 fetch 成 bitmap、
   全解析度疊成一張長圖、一個 `<a download>` 蓋滿畫面、按一次，再用 PIL 切開。
   無損，而且把 N 次下載壓成 1 次（避開 Chrome 的「自動下載多個檔案」封鎖）。
