### ⚠⚠ 主幹刻意「按不到底」（憲法 ver -902 的自檢）

實走結果（產生器每次都會印）：

```
一直按↑（從入口）：地宮入口→前廳→石階廳→轉輪室→水牢→柱林→中央大殿      ← 停在這裡
一直按↓（從玉座）：玉座間→御前廊→龍紋階→儀衛廊→水鏡池→階梯井→沉香室→暗渠→舊墓道→碑林廊
```

- 兩個方向都**走到某一格就停**，沒有同向繞圈（-902 那個「兩格之間彈、走不出去」的病）。
- ⚠⚠ **而且按↑到不了玉座間** —— 玉座區刻意掛在**西側的儀衛廊**，不掛中央大殿。
  掛中央大殿的話主幹就是一條直通王座的電梯，十一個岔路口全白設計了。
  玩家得自己找到「在中央大殿往西轉」那一步。
- ⚠ **柱林層與水牢層的橫向各斷成兩段**（階梯井↔柱林、三岔廳↔水牢 **沒有路**）：
  那兩個斷點是「東半邊與西半邊要繞路才過得去」的來源，也是四個環的成因。

## 二、逐格特徵（**辨識度**＝這一節）

> Ray：「不要都畫一樣，要有辨視度」。
> ⚠⚠ **憲法 §6.5.4「地圖的形狀是圖決定的」是反過來用的**：這一次**先排拓樸再畫場景**，
> 所以下面的「出口數」是**給美術的規格**，不是事後遷就 —— 那一格的背景圖**必須**
> 畫得出那麼多條真通道（壁龕假路不算）。畫不出來就回頭改拓樸，不要硬接。

### 四向口（背景要畫得出四條真通道）

| 格 | 這一格長什麼樣 |
|---|---|
| **御前廊** | 玉座前的短廊。左右各一道包金釘的大門（冕旒室／供物室），正面是玉座的高門，身後往下是龍紋階。地上散著朝服的殘骸。 |
| **儀衛廊** | 兩排**等身石甲武士**夾道，每一具都缺一隻手。四面都是拱門，甲士的臉朝著走道轉。 |
| **舊墓道** | 墓道的十字口。四壁密密麻麻的小龕，每一龕一盞熄掉的燈。 |
| **石階廳** | 入口正上方那一層。寬石階往下通前廳，其餘三面各一道券門；地上積了一層細沙，看得出腳印。 |

### 三向口（十一個，**每一個岔法都不一樣**）

| 格 | 這一格長什麼樣 |
|---|---|
| **中央大殿** | 整座地宮最大的廳，天頂垮了一半**但沒有天光**（上面還壓著一層）。八根倒柱斜插在地。 |
| **燈火廊** | 長廊兩側整排壁燈，**只有離你最近的三盞是亮的**，走近就依序亮起來。 |
| **壁畫迴廊** | 弧形的廊，內壁一整幅褪色壁畫（王的一生），畫面被三道門切斷。 |
| **階梯井** | 方形的樓梯井，梯級繞著井壁盤下去，**正中央是空的**（看得到下一層）。 |
| **柱林** | 幾十根等距的方柱，看不到牆 —— 方向感只能靠柱距。 |
| **龍口渠** | 水從一座石雕龍口流出、沿廊而下；渠兩側各一條窄步道。 |
| **鍛冶遺室** | 塌了一半的鑄場：冷掉的爐、掛滿工具的牆、地上一灘凝固的金屬。 |
| **三岔廳** | 正三角形的廳，三面各一個門洞，正中一口井。 |
| **水牢** | 地面全是及膝的水，牆上一排鐵柵小室，柵欄泡在水裡。 |
| **骨櫃廊** | 兩側牆整面是抽屜狀的石櫃，**有幾格被拉開了**。 |
| **轉輪室** | 正中一座巨大的木製絞盤（開門用的），鎖鏈往三個方向的牆裡去。 |

### 通道（二向）

| 格 | 這一格長什麼樣 |
|---|---|
| 龍紋階 | 一段長石階，兩側扶手雕成龍脊。 |
| 水鏡池 | 一池不流動的黑水，水面照得出天頂的藻井。 |
| 沉香室 | 小方室，四壁嵌著香爐，空氣裡還浮著煙。 |
| 暗渠 | 要低頭走的排水暗渠，水到腳踝。 |
| 鏡廊 | 兩側牆嵌滿磨過的銅鏡，把光一路傳下去。 |
| 燭廊 | 窄廊，地上插滿滴乾的蠟燭。 |
| 碑林廊 | 走道兩側立滿石碑，人要側身過。 |
| 積水甬道 | 低窪甬道，積水到膝，壁上有一條清楚的水痕線。 |
| 前廳 | 入口內側的門廳，一半塌了，**回頭看得見外面的光**。 |

### 端末口・室內（8）

| 格 | 這一格長什麼樣 |
|---|---|
| **玉座間** | 最深處。一座**空的**玉座，背後是整面浮雕。（建議＝BOSS 格） |
| 冕旒室 | 擺著王冠與冕旒的小室，架上的東西都還在。 |
| 供物室 | 堆滿祭器與乾掉供品的側室。 |
| 星圖室 | 穹頂刻著整片星圖的圓室，地上一具青銅渾儀。 |
| 藏骨堂 | 牆面砌滿頭骨的圓堂。 |
| 鐘室 | 吊著一口大銅鐘，鐘身有一道裂縫。 |
| 守衛塚 | 陪葬武士的墓室，成排的石棺。 |
| 獸檻 | 關過什麼東西的鐵籠，**柵欄是從裡面被撞開的**。 |

### 端末口・**戶外**（4）

> Ray：「某些端末點是戶外」。四個都是「地宮破開、天露出來」，但**看見天的方式
> 各不相同** —— 這正是辨識度：玩家一眼就知道自己走到哪一個破口。

| 格 | 這一格長什麼樣 |
|---|---|
| **天井中庭** | 下沉式中庭，四面石牆，**天空在正上方**；地面長滿草與小樹。白天有陽光直射到底。 |
| **崩頂裂口** | 天頂整片塌下來，碎石堆成一道**斜坡通向外面**；坡頂看得到雲。 |
| **排水崖口** | 排水道的出口開在**崖壁上**，往外是峽谷與遠山 —— 腳下沒有路。 |
| **枯井底** | 井底抬頭是**一個圓形的天**；井壁長滿藤，藤一路垂到地面。 |

⚠ 四張都要有**時段差分**（`_dawn`/`_day`/`_dusk`/`_night`，§5）—— 室內那些不必。
這是它們最大的成本，也是它們最大的價值：整座地宮只有這四格會隨時間變。

## 三、接進遊戲時要注意的（等 Ray 點頭之後）

- ⚠ **入口那一格不可以有戰鬥**（§6.5.2）：`前廳`（＋`地宮入口`）留空。
- ⚠ **樓梯／裂隙不出怪**（ver -913 的通則）：`龍紋階`／`階梯井`／`崩頂裂口`／`枯井底` 建議 `noWild`。
- ⚠ **休息處**（`rest:true`，走進去就閉棺結算）：建議 `前廳`（入口）＋ `天井中庭`（中段喘息）。
  ⚠ 安全點一律 `noWild`。
- ⚠ **結算怪**：這張圖只有一個跨圖出口＝**末端型**，所以 ver -895「擺在沒走進來的
  那個出口」不適用，結算怪照舊由資料指定（建議 `玉座間` 的 BOSS）。
- ⚠ **迷霧預設是有的**（ver -913）：這張圖**不要**寫 `mist:0`。
- ⚠ 小地圖（`resources/map/map_undercity.png`）是**另一張**手繪羊皮紙圖，等拓樸定案
  再請美術畫 —— 節點數一變那張就得重畫（-901 已經重畫過一次）。
