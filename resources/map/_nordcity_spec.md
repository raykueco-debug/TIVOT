## 二、風格：**北歐・1900 年**

### ⛔⛔ 硬禁令（Ray 指定）

> 「**不要有任何旗幟跟國標**」

· ⛔ 不要旗子、不要旗桿、不要三角旗與串旗、不要船旗。
· ⛔ 不要國徽、市徽、盾徽、紋章、王冠、雙頭鷹、十字旗那一族。
· ⛔ 招牌上不要任何國家或官方的標誌 —— 商家招牌用**器物剪影**（鑰匙、麵包、酒桶、火槍）。
· ⚠ 行政廳也一樣：正面可以有大鐘與石雕花飾，但**不掛任何徽章**。

### ✅ 1900 年的北歐要畫什麼

| 要 | 怎麼畫 |
|---|---|
| **木造倉庫街** | 沿水邊一排排三四層的木造貨棧，山牆正對街、頂端有**吊貨的伸臂與滑輪**；外牆漆成赭紅、赭黃、暗綠，木板橫向密鋪 |
| **民族浪漫主義的石造建築** | 粗面花崗岩砌的底層、圓拱窗、厚重的塔樓與洋蔥／圓錐頂；線條沉穩、裝飾少 |
| **Jugendstil（新藝術）** | 只出現在比較新的臨街立面：帶曲線的窗框、鍛鐵陽台、植物紋的浮雕 |
| **屋頂** | 深色石板瓦或銅皮（生銅綠）；屋脊高陡（落雪用），老虎窗成排 |
| **街面** | 花崗岩方石鋪地、有車轍；鑄鐵**煤氣路燈**、繫馬環、排水溝 |
| **氣候** | 冷。空氣裡有海霧或煤煙，遠處被霧吃掉一階；屋簷與石縫有殘雪或水漬 |
| **1900 年的證據** | 電線與電報線橫過街道、早期的路面電車軌道（車可有可無）、玻璃櫥窗、鑄鐵柱廊 |

⛔ 不要：中世紀半木構（Fachwerk）、城牆與雉堞、南歐的赤陶瓦與拱廊、
現代玻璃帷幕、柏油、汽車、霓虹。
⛔ 絕對不要東方元素。

### 色調
低彩度的冷色：石灰白、花崗岩灰、赭紅木、銅綠、深藍灰的天。
暖色只從**窗內的燈光與煤氣燈**來 —— 那是這座城唯一的溫度。

## 三、⬜ 先留白的三格（Ray 指定）

| 格 | 為什麼留白 |
|---|---|
| **行政廳 `cityhall`**（＝Ray 說的「市鎮中心」） | 這座城的權力長什麼樣是世界觀的事 |
| **碼頭 `dock`** | 港城的門面，船的種類與飛空艇的位置由 Ray 定 |
| **大教堂 `church`** | 同上，宗教建築的形制是世界觀的事 |

⚠ **一開始我讀錯了**：把「市鎮中心」讀成 `midtown`（中心區），
Ray 更正「**是行政廳那一格留白**」。所以留白的是 `cityhall`，`midtown` 要畫。

⚠ **留白＝先不寫美術簡報、先不畫**，不是「不接進遊戲」：
節點照樣存在、出口照樣接好，`bg` 的檔名也先定好（`Nord_Cityhall`／`Nord_Dock`／`Nord_Church`），
這樣 Ray 一給方向就能直接補圖，程式端不必改。
⚠ 在圖交出來之前，那三格由程式端掛 `bgPending:true`（同伊甸古墓的作法），
`script_lint.py` 只報提醒不報錯。

## 四、逐格美術簡報（**九格**，留白的三格不在內）

⚠⚠ **中心區那一格有一個伏筆**：它看得到通往行政廳與大教堂的兩條側街，
而那兩格是留白的 —— 所以簡報寫死「**側街往深處沒入海霧**」。
這樣日後那兩格定案時，中心區**不必重畫**，霧裡本來就沒有承諾任何形狀。

| 格 | 向數 | 這一格長什麼樣 |
|---|---|---|
| **港口廣場** `square` | 3（＋出航） | 城的入口：一塊花崗岩鋪成的方形廣場，一側就是碼頭的水面與繫纜柱；中央一座**鑄鐵的飲水槽或無雕像的紀念石柱**（⛔ 不要人像、不要徽章）；三面是四層樓的石造街屋，底層是鑄鐵柱廊的店面；煤氣燈成列；地上有電車軌道與車轍 |
| **中心區** `midtown` | 3 | 全城最寬的一條石板大道：兩側是四五層的粗面花崗岩街屋，底層是鑄鐵柱廊的店面；路中央有電車軌道與架空電線，行道樹（菩提，已落葉）等距排開；煤氣燈成列往深處縮小。⚠⚠ **左右兩條側街要往深處沒入海霧**（那兩頭分別通行政廳與大教堂，而那兩格還沒定案）—— 霧裡只看得到一團模糊的量體與一點燈光，**不要畫出可辨識的塔或尖頂** |
| **舊街區** `oldtown` | **4** | 最老的一區：狹窄的石板巷，兩側是傾斜的木造貨棧，山牆頂端伸出吊貨臂與滑輪；巷子上方橫著電線與晾衣繩；四個方向各一條走得進去的路（其中一條往下是地勢較低的巷口） |
| **武器店** `gunstore` | 末端 | 店面在石造街屋的底層：厚重的木門與鍛鐵門環，**櫥窗裡陳列著獵槍與彈帶**；招牌是一支火槍的鐵剪影（⛔ 沒有文字國標）；牆上掛著鹿角 |
| **賞金獵人公會** `guild` | 末端 | 半地下的入口、往下幾階；門旁一整面貼滿紙的木製告示板，紙角被風掀起；門上一盞防風玻璃燈；⛔ 告示板上不要徽章，只有手寫的紙與圖釘 |
| **上街區** `uptown` | **4** | 地勢較高的新街區：Jugendstil 的臨街立面、曲線窗框與鍛鐵陽台、成排的行道樹（已落葉）；街道較寬、有分隔的人行道；遠景看得下去整片赭紅屋頂與港灣的桅杆 |
| **餐飲街** `tavern` | 末端 | 一條窄街，兩側是地下室的酒館入口與亮著燈的玻璃櫥窗；戶外沒有座位（太冷），只有靠牆的立桌與煤氣暖爐；門口掛著酒桶與麵包的鐵剪影招牌 |
| **雜貨舖** `grocery` | 末端 | 底層的店：大片玻璃櫥窗，裡面堆著麻袋、罐頭、繩索、油燈與桶裝鹹魚；門口一台磅秤與幾隻木箱；招牌是一把鑰匙與一個桶的鐵剪影 |
| **旅店** `inn` | 末端 | 三層的木石混造：底層是粗面石、上兩層是赭紅木板；門廊有雨庇與一盞大燈；二樓窗內透出暖光；門邊一塊掛著鑰匙剪影的鍛鐵招牌 |

### ⚠ 每一格的向數是那張圖要畫得出來的（§6.5.4）
- `oldtown` 與 `uptown` 是 **4 向**：圖上要看得到四條真的走得進去的路。
- `square`／`midtown` 是 3 向。
- 其餘九格是末端：**畫得出「這裡走到底了」**。
