## 一、接點：**大地圖上那座 `ruin:'stone'` 就是這張圖的入口**

`flight/index.html` 的 `PLACES` 已經有這一筆（ver -1107）：

```js
{x:1125,y:757, name:'石製遺跡', type:'遺跡', sense:true, flag:'ruin_b_found', ruin:'stone'},
```

它**現在沒有 `town:`** —— 那一行的註解自己寫著「那座遺跡的地圖內容還沒有。
做好了就補 `town:`」。**內容現在有了**，所以要做的是：

```js
{x:1125,y:757, name:'石製遺跡', n:'石製遺跡', type:'遺跡',
 sense:true, flag:'ruin_b_found', ruin:'stone', town:'fallen'},
```

- `n:` ＝降落鈕上的字（`doLand` 讀 `S.n`，同 `SETTLEMENTS` 欄名，照夏爾森林那一列）。
- ⚠ **不要進 `SETTLEMENTS`**：那張表會被道路網與程序建築當成城。
  著陸掃描（`nearestTown`）本來就兼掃帶 `town` 的 `PLACES`，**程式不必再改**。
- ⚠ `sense:true` 保持不動 —— 它仍然是隱藏點（要安雅感知才掃得到名牌），
  但地上的斷柱一直看得見，那是玩家會飛過去按的理由。
- ⚠ 另外那一筆 `{x:1144,y:788, name:'無名遺跡', flag:'ruin_a_found'}` **不是這一座**，
  它到現在還沒有內容，不要接錯。

## 二、拓樸：**5 格・4 邊・環數 0**（樹狀，一條路到底，中間一次岔路）

```
                 祭壇
                  │
   沉水石坑 ──── 傾石岔口        ← 唯一的岔口（三向）
                  │
                斷柱道
                  │
                崩塌門廊  ← 入口（下方＝出航）
```

| 節點 id | 中文 | 背景基底名 | 出口 |
|---|---|---|---|
| `entry` | 崩塌門廊 | `Fallen_Entry` | `{ up:'causeway' }` ＋ `sail`（下方＝離開，見下） |
| `causeway` | 斷柱道 | `Fallen_Causeway` | `{ up:'fork', back }` |
| `fork` | 傾石岔口 | `Fallen_Fork` | `{ up:'altar', left:'basin', back }` |
| `basin` | 沉水石坑 | `Fallen_Basin` | `{ back }` |
| `altar` | 祭壇 | `Fallen_Altar` | `{ back }` |

### ⚠⚠ 佈局圖上那個「原野（跨圖）」要改成**出航**

`_layout_fallen.png` 畫的是「從別張圖走進來」，那是提案階段的假設。
**實際的進出是降落／起飛**（這座遺跡在大地圖上是獨立的一點，沒有鄰接的地面圖），
所以 `entry` 的下方掛 `sail`，不是 `@某張圖`：

```js
sail:{ flag:'got_ship' },   // 欄位長相照 northport 的 entrance
```

⚠ 這是**我的判讀**，不是 Ray 明說的 —— 日後若要從夏爾森林那邊走過去，
把它改成 `down:'@某圖:某格'` 就好，拓樸本身不必動。

### 拓樸的三道自檢（憲法 §6.5.4，接完請跑過）

1. **同一條邊兩端必須相反**：`A.up→B` ⇒ `B.down→A`。
   這張圖的過道與末端一律寫 `{ up:<前進>, back:<退回> }`，**不要寫死 `down`**
   （`back` 由 `exitsOf` 現算成來時方向的反向，ver -903）。
2. **一直按 ↑**：崩塌門廊 → 斷柱道 → 傾石岔口 → 祭壇，走到底就停（沒有同向繞圈）。
   一直按 ↓ 應該原路走出去。
3. `tools/script_lint.py` 會驗出口指到不存在的節點／單向邊／兩端同名。

### 每一格的向數**是那張背景圖畫得出來的**（§6.5.4，ver -890）

| 格 | 向數 | 圖上的依據 |
|---|---|---|
| `entry` | 2 | 門框中央一條路往深處；身後是來路 |
| `causeway` | 2 | 直廊，兩側是倒下的圓柱排，沒有側向開口 |
| `fork` | **3** | 三塊斜倚石板撐出三角空地，**三個方向各一條真的走得進去的路** |
| `basin` | 1 | 四面被石牆與土坡圍死 |
| `altar` | 1 | 路的盡頭 |

⚠ **不要多接**：多接是說謊，少接只是「那邊沒路」。要更多分岔就回頭跟我要圖。

## 五、其餘欄位的建議值（照既有的遺跡那一級）

| 欄位 | 值 | 依據 |
|---|---|---|
| `wilderness` | `true` | 野外的路沒有門可以關（19:00 全域打烊不罩，ver -862） |
| `mist` | `1`（或不寫） | **迷霧是預設**（ver -913）；沒有人帶路，走過才亮 |
| `stepMin` | `10` | 遺跡那一級（ver -917，Ray：「遺跡內每次移動 10 分鐘」） |
| `storyExplore` | `true` | 女角不排外出行程 —— 這裡不是城 |
| `bgm` | 待定 | 神殿是 `frosylva`、森林是暫代的 `misty`；這一座 Ray 沒給 |

⚠ 以上是**建議**不是決定，尤其 `bgm`。
