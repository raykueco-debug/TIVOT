## 二、拓樸（**ver -1494：Ray 定案**，`reference/lake_topology.pdf`）

⚠⚠ Ray 把**終點移到側鏈的盡頭**：主軸走到湖心石堤（看得到湖面），
而真正的終點**石碑林藏在另一條路的底**。10 格・9 邊・樹狀（環 0）。

```
                      causeway 湖心石堤（末端）
                            ↑ up
 monolith 石碑林（終點）      northshore 北岸 —right→ boathouse 廢船屋（死路）
      ↑ up                      ↑ up

      ↑ up                      ↑ up
 fallbase 瀑布底 ←left— shingle 碎石灘
                            ↑ up
                        inlet 山口（入口・不可有戰鬥）
```

| 節點 | 向數 | 出口 | 畫面上要看得見的路 |
|---|---|---|---|
| `inlet` 山口 | 1 | `up→shingle` | 隘口，前方第一次看到湖 |
| `shingle` 碎石灘 | 3 | `up→eastshore, left→fallbase`（＋back） | 正前方沿湖的路、**左邊一條往岩壁下的岔路** |
| `fallbase` 瀑布底 | 2 | `up→cave`（＋back） | 瀑布注入湖面；**岩壁上有一條往上的石階／坡** |

| `monolith` **石碑林** | 1 | `back→cave` | ✔ **已交件**（ver -1493） |
| `eastshore` 東岸 | 3 | `up→northshore, right→deadfall`（＋back） | 沿湖的路、**右側水邊一條岔路** |
| `deadfall` 倒木灣 | 1 | `back` | 死路：泡在水裡的枯木堆 |
| `northshore` 北岸 | 3 | `up→causeway, right→boathouse`（＋back） | 正前方一條石堤伸進湖心、**右側一座半沉的船屋** |

## 四、⚠⚠⚠ 發光版**不要叫模型畫**，用本機合成

**第一版就是叫模型畫的，它把符文重畫成完全不同的圖案**（原本滿面的菱形格紋
變成幾個大符號），而且地面與水面也跟著動了 —— 違反「一道都不要多、一道都不要少」。

⇒ 改成**從熄滅版鍵出刻痕再疊光**，構圖 100% 不可能變。作法（`scipy` 這台裝不起來，純 PIL＋numpy）：

```python
roi   = 只框「刻符文的那一面」            # ⚠ 見下
stone = roi & (灰階 < 118)                # 石碑很暗
stone_in = MinFilter(9) 侵蝕一圈          # ⚠ 石碑的**輪廓**也比背景暗，不縮的話整圈發光
rune  = stone_in & (GaussianBlur(灰階,7) - 灰階 > 14)      # 刻痕＝局部比周圍暗
core/halo/far = blur(rune, 0.8 / 6 / 20)
疊法：screen，強度 core 0.92 / halo 0.55 / far 0.22，石面先 ×0.92 壓暗
光色：冷銀藍白 (176,224,255)
```

⚠⚠ **ROI 只框符文那一面**（實測 `x 358~512, y 85~720`）：石碑左半是**裂縫**，
而「局部比周圍暗」分不出裂縫與刻痕 —— **整根石碑的裂縫會一起亮**（踩過）。
用位置排除比事後修遮罩可靠。
⚠ 強度要**放大到 100% 看**（憲法 §5）：縮圖上看起來剛好的，放大是糊成一團；
  第一版 core 1.0 整根石碑變一團光、第二版 0.62 又幾乎看不見。

⚠ 光色目前是**冷銀藍白** —— Ray 沒指定顏色。要換成金／紅講一聲（改一個常數重跑）。
