# 木雅克神殿 — 3D 量體的素材需求（ver -1229）

> Ray：「柱太多太細太長，長得不像外觀，我讓美術生個外觀圖給你」

**現況**：`RUIN_ART.muyak`（`flight/index.html`）42 個零件，最高 62 世界單位，
沿牆 312、進深 156。它是我**照 `resources/background/Forest_Cliff_Day.webp` 用眼睛排的**
—— 而那是一張**遠景**：看得出剪影與色調，量不出每一塊的平面位置與粗細。
Ray 說的「太多太細太長」正是估出來的那一半。

---

## 一、⚠⚠⚠ 一張外觀圖能解決什麼、**不能**解決什麼

這是貝利薩爾那一輪就踩過的（見 `_belisar_massing_spec.md`）：
**透視／仰角的外觀圖量不出平面位置**。

| 外觀圖**能**給我的 | 外觀圖**給不了**、只能靠第二張或我猜的 |
|---|---|
| 塔與柱的**數量** | 每一塊的**平面位置**（哪一支在前、哪一支在後、偏多少） |
| **粗細與高度的比例**（柱有多粗、比牆高多少） | 進深方向的**層次**（幾排、每排退多少） |
| 牆段的**長短節奏**與缺口 | 整體的**不對稱** |
| 開口的大小與數量 | |
| 整體剪影 | |

⇒ **只要一張外觀圖，就足夠解掉 Ray 這一次說的三件事**（太多／太細／太長）——
那三件都是**比例**問題，外觀圖量得出來。平面位置那一半可以先不動。

⚠ 想一次做到「與外廓完全一致」才需要第二張（正俯視高度圖），見 §三。

---

## 二、外觀圖的規格

- **一張正面（或略斜）的外觀圖**，木雅克神殿的全景：整座在畫面內、不要裁切。
- 視角**放低、接近水平** —— 高度比例要量得準；俯角太大會把高度壓掉。
- 背景單純（天空／遠山即可），**不要前景遮擋**（樹、岩石擋住柱腳就量不到高度）。
- 這座的設定：**藏在山坳裡的石造神殿廢墟**，長滿苔的風化石灰岩
  （材質已定案：`flight/geo/moss_stone.webp`，色 (179,183,176)）。
- 形制參考已定案的那張遠景 `resources/background/Forest_Cliff_Day.webp`：
  帷幕牆＋拱形開口＋中央門樓＋兩端塌矮的斷牆。
  ⚠ Ray 的意見是**柱要少、要粗、要矮** —— 畫的時候往「厚重的石造殘牆」走，
    不要往「一排細長的立柱」走。
- 畫風四鐵則照憲法 §5（**提示詞結尾要帶完整那一句**）：
  `anime style, cel shading, clean lineart，絕不要顆粒感、不要雜訊噪點、不要油畫質感`
- ⚠ 這一張**是插畫**，所以四鐵則適用。（§三那張高度圖是技術圖，**不適用**，見下。）

## 三、（可選）第二張：正俯視高度圖 —— 要「完全一致」才需要

⚠⚠⚠ **這一張不是插畫，是技術圖**：§5 那四條畫風鐵則**不適用也不要套**。
要的是精確的形狀與精確的灰階 —— 不要光影、不要材質、不要描邊、不要透視。

- 底圖已經產好了：**`flight/Reference/muyak_plan_h_draft.png`**
  （383×1167、3 px／世界單位、**白 = 80 世界單位**），美術在上面改形狀就好，
  不必從零畫，也保證與程式端的座標系對得上。
- 產法：`python3 tools/ruin_heightmap.py muyak 80`
  ⚠ 第二個參數是 `HMAX`。它原本寫死 320（照貝利薩爾的 302），而木雅克最高只有 62
  —— 用 320 畫出來整張只有 19% 的灰，**美術根本看不出形狀**。ver -1229 起可以逐座給。
- 灰階是**線性**的：0 ＝ 地面、255 ＝ 80 個世界單位。
- ⚠ 屋頂的**坡**、雉堞、開口、材質都表達不出來，那些照舊由程式端產生；
  這張只管**量體與 footprint**。

---

## 四、交件之後程式端做什麼

1. 量外觀圖：塔的**數量**、每一支的**寬高比**、塔比牆高多少、牆段的長短節奏。
   （量法同 `RUIN_PAL.mossgrey` 那一次：用低彩度的像素把石頭挑出來再量。）
2. 照量到的比例改 `RUIN_ART.muyak.parts` —— 先改**粗細與高度**（Ray 這次說的），
   平面位置維持現況。
3. 跑 §6.8.1 §五那套資料自檢（開口包在牆裡／沒有零件浮空／露底 0%）＋
   三個距離的截圖。
