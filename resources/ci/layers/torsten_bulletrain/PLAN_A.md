# Bullet Rain（托爾斯滕彈雨傾洩 CI）— Plan A：關鍵格＋格號，一次生成

> 2026-10-08 Ray 定名「Plan A」。目前只是文字討論，**等 Wan（含 VACE）建好跑一次看效果**再決定採不採用。

## 問題
- Wan I2V 生出來的動作是**等速、平均分布**的，太勻。
- 只刪格（減禎）抓節奏 → 快的那一下變成「瞬移」，沒有速度感。
- 想要手繪動畫那種「最快的那一下只閃一張拉糊的過渡格」（smear frame）。

## Plan A
把粗剪要表達的東西改寫成**原畫＋律表**，交給 Wan VACE 一次生成：

1. **關鍵格**（原畫）：
   - A＝`wan_in/A.png`（槍不在畫面、頭微低）
   - B＝`wan_in/B2.png` 或 `wan_in/B3.png`（槍從左右甩入、水平速度模糊、頭仰起；B3 仰得較多，兩張都留，跑了再挑）
   - C＝`wan_in/C.png`（雙槍指鏡頭、低頭鎖定）
2. **律表**：每張釘在第幾格，例如 A＝第 0 格、B＝第 k 格、C＝第 N 格。
   **速度由間隔決定**：A→B 間隔短＝快甩；B→C 間隔長＝慢慢低頭鎖定。
3. VACE 把中間格一次補出來：
   - B 原封不動卡在第 k 格，前後都是正常的清楚格，就是「只閃一張」的過渡格效果。
   - 整支一次生成，**沒有兩段拼接的接點**（Ray 退過的接縫問題不會出現）。

## 為什麼不用「拿跳動的粗剪去生不跳的版本」
用粗剪當動作參考的話，模型會照著粗剪走，連跳動一起學走；要是它把跳動抹平，又會把剪出來的快慢一起抹平，兩個目的互相打架。

## 需要
- **Wan VACE 模型**（Wan2.2 VACE，Q4 約 10～15 GB）。現裝的 Wan2.2 I2V 只吃頭尾兩張，B 擺不進中間。
- 這台是 3060 **12 GB** 顯存，要實測跑不跑得動。
- 四張輸入都已在 `wan_in/`，同一張 1064×1596（2:3）畫布，只在上方補透明，四角補 alpha 12 的點，讓外框一致。

## 測試順序
1. Wan I2V 裝好 → 先照原計畫跑 A→B（B2、B3 各一支），讓 Ray 感受 Wan 的動作、抓格數間隔。
2. VACE 到位 → 用 Ray 定的 k、N 跑 Plan A 一次。
3. Ray 看完決定：採用／調 k、N／改走別的做法（例如沿動作方向拉糊的後製過渡格）。

## 同一個 VACE 的另一個用途（之後一定會碰到，先記著）
大幅剪節奏後頭髮跳格 → 每格用遮罩框出頭髮，只重畫頭髮，身體與槍完全鎖住。
