# 有翅巨龍（`mon_dragon_*`）— 美術規格

> Ray（2026-09-11）：「生一個**有翅的西方龍**，**三種型態**，**不要長得太傳統**，
> 有點像**巴哈母特、青眼白龍**那樣的**異型巨龍**，**不要被看出來設計照抄**，
> 只是給你方向，**alpha 去背**」

**三張是同一隻**，不是三隻怪 —— 一場 BOSS 戰的三個階段。

---

## 一、這一隻的設定（三個型態共用）

> ⚠⚠⚠ **ver -1057 大改方向**（Ray 看完前四輪）：
> 「**已經不像龍了，不用宗教元素**，讓人**一眼看得出是巨龍**，巨型 boss 的威壓，
> **純粹強大生物產生的壓迫感**，參考青眼白龍跟巴哈姆特，**不是傳統面部尖銳的西方龍**」

| | |
|---|---|
| **讀得出是龍** | 四肢、粗長的頸、粗長的尾、一對巨大的**膜翼**、有角的頭 —— 一眼就是龍 |
| **壓迫感的來源** | **只有生物本身**：肌肉、骨、牙、爪、體積。⛔ 不靠鎖鏈／光環／符文／聖器／浮空物件 |
| **體格** | 極度壯碩：粗頸、桶狀胸廓、巨大的肩與胸肌（翼的動力來源）、粗壯的趾行後肢、又粗又長當配重的尾。大腿上臂明顯比小腿前臂粗 |
| **頭** | ⚠⚠ **不是傳統西方龍那種又長又尖的吻**。**寬、厚、鈍**的重型頭骨：深而方的下顎、厚實的眉骨與顴骨、**少數幾根粗大向後掠的角**（整體輪廓像頭盔）；嘴閉著幾乎看不到牙。**眼睛小而深陷，冷白偏藍的強光** |
| **表皮** | 象牙白到灰白的**鱗與天然骨板**（長在身上，不是裝上去的），胸腹較深的灰；脊背與前臂成排的厚甲脊。要**大塊硬質板**，不要細碎鱗刺 |
| **翼** | **真正的膜翼**：粗壯翼骨，翼膜深灰藍、薄處透光；翼根與胸肌相連處看得到肌肉 |
| **配色** | 象牙白／灰白的體、深灰的腹與翼膜、暗骨色的角與爪、**冷白藍光的眼**。低彩度 |

### ⚠⚠⚠ 「參考但不照抄」怎麼拿捏

| 參考 | 取 | 不取 |
|---|---|---|
| 青眼白龍 | **蒼白的體色**、**發強光的眼**、**巨大** | 流線光滑的身體、藍色的眼、纖細比例 |
| 巴哈母特 | **重裝甲般的體格**、**頭盔輪廓的頭** | 深色金屬、機械感、人形站姿 |

⇒ 換掉的核心是**體型與頭型**：把「裝甲」改成**天然長出來的骨板**、把尖吻改成**寬鈍的重型頭骨**。
兩者都是**生物特徵**，所以既避開照抄，也守住「壓迫感來自生物」這一條。

### ⚠⚠⚠ 被推翻的前四輪（留著當紀錄，不要走回去）

v1~v4 走的是「**教會器物長進生物身上**」那條路（陶質骨甲＋金線＋彩繪玻璃翼＋鎖鏈＋
沒有臉的板甲頭殼＋浮空聖器殘片），想接回本專案 `mon_relic_*` 的既有文法。
**Ray 退回的理由是「已經不像龍了」** —— 那些元素堆上去之後，剪影讀起來是
「聖遺物系的一員」而不是「一頭龍」。

⇒ **教訓**：`mon_relic_*` 的文法是給**人形集合體**用的，套到「要一眼看得出是什麼生物」
的怪身上會把物種特徵蓋掉。**先確定牠讀得出是什麼，再談世界觀的裝飾。**
⚠ 前四輪的圖 Ray 說過留著（v1「這個可以保留」、v2「也不錯」），放 `_drafts/`。

## 二、三個型態（差別在**剪影**，不只在細節）

| 型態 | 檔名 | 剪影 | 這一階段長什麼樣 |
|---|---|---|---|
| **拘束態** | `mon_dragon_shackled` | **厚重、蜷縮、往下壓**（橫向的一團） | 四足伏地、前身壓低、肩胛高過頭；翼收攏貼背，彩繪玻璃**碎掉好幾片**只剩空骨架；頭上扣著沉重的**鐵口枷／冠環**，鎖鏈穿過甲片**長進肉裡**；內光微弱偏暗紅，像將熄的炭 |
| **解縛態** | `mon_dragon_unsealed` | **高而寬的十字形** | 後肢直立、雙翼全展、玻璃完整且背光透色；斷鏈甩在空中，口枷被撐裂掛在下顎；**頭殼沿正中線裂開**露出細長內顎、針狀牙與一排**縱向的眼睛**；肋側再展開一對副肢（共六肢）；內光轉亮紅 |
| **神化態** | `mon_dragon_ascendant` | **垂直、發光、失重** | 懸空；下半身沒有腿，散成向下拖曳的鎖鏈與布幡；翅膀變**三對**、在背後排成一圈像**光背**；**頭不見了**，原位只剩一圈懸浮的**刃狀冠環**、環中是白熱的光，眼睛改沿頸與胸的縫隙排開；周圍漂浮繞行的**碎石構件與聖器殘片**；內光轉白金 |

### ⚠⚠⚠ 「壯碩」是這一族的第一順位（ver -1054）

> Ray 看完第一版：「**太纖太細太刺，要壯碩點**」

第一版把「異型／瘦長／接近鳥與昆蟲的比例」寫得太重，結果三張都變成**細長帶刺**的剪影。
判準改成一句話：**讀起來要是「一堵會動的牆」，不是「一把刀」** ——
剪影要**填得滿、重心低、壓得住畫面**。
⚠ 「異型」保留的是**質地與臉**（陶質骨甲／金線／彩繪玻璃／沒有臉），**不是瘦**。
　那三件事本身就夠把它和巴哈母特、青眼白龍分開了，體型不必再往細長推。
⚠ 第一版那三張**留著**（Ray：「這個可以保留」）—— 當同一隻的另一種可能，不是廢稿。

### ⚠⚠⚠ 第二版的三個修正（ver -1055，Ray 看完壯碩版）

> 「這隻也還差了點，但是也不錯，可以畫完，**翅膀不要破碎**，**要有 boss 的威壓感**，
> **三張之中要有一張是攻擊態勢**」

1. **翅膀一律完整** —— 三張的彩繪玻璃翼膜**每一片都在**，不缺角、不只剩空骨架、不撕裂。
   ⚠ 這推翻了初版「拘束態的玻璃碎掉好幾片」那一條：破損讀起來是**弱**，不是**被封印**。
   拘束態改成**收攏但完整、暗沉不透光**，張力交給**被繃直的鎖鏈**。
2. **威壓感要寫成「怎麼畫」**（同 §5「遼闊」那條的道理，寫「要有威壓感」沒有用）：
   · 鏡頭**極低、幾乎貼地往上仰**，牠**佔滿畫面高度**，頭頂頂到上緣
   · **近端部位強透視誇張放大**（伸向鏡頭的爪／肩／下顎），遠端急縮
   · **肩與胸的量體壓過頭** —— 頭相對小、身體相對巨大，才會「大得不合理」
   · 身體**向前壓過來**像要越出畫框；重心低
   · 可以有少量**餘燼與塵屑貼著身體周圍飄**
   · ⚠ **仍然不畫地面、不畫影子、不畫環境** —— 背景全透明是硬條件，威壓只能靠視角與量體
3. **第 2 張（解縛態）＝攻擊態勢**：正在撲過來，一隻粗爪已經揮到鏡頭前、爪尖朝觀者、
   強透視放大到快出框；內顎大張、一排眼全亮；斷鏈在空中拖出動勢。
   ⚠ 三個型態裡只有這一張是動作張，另外兩張是**蓄力**與**俯視** —— 三張都在動會互相抵消。

⚠⚠ **三張的剪影要先分開才寫提示詞**（憲法 §5：同一族連著畫剪影會趨同）——
這一組刻意做成 **橫 → 十字 → 直**，縮成 1/4 也分得出是哪一階段。

## 三、規格（同 `_relic_spec.md` 的硬條件）

- 直式 **1024×1536**、**全身入框**（翼／尾／爪／角都不可裁到）、**透明背景（alpha）**。
- anime style／cel shading／clean lineart／**絕不要顆粒感、雜訊噪點、油畫質感、3D 渲染感**。
- 線稿分主副線、陰影 3~4 階硬邊、甲牙爪角畫出斷面與厚度。
- 調性：DMC／惡魔城／The Last Faith／Blasphemous／Elden Ring／隻狼／Dark Souls
  —— ⚠ 只取題材與剪影，不要出現那些作品的具體角色或紋章。
- **氣勢寫在第一趟**（憲法 §5）：低視角由下往上、正面朝鏡頭、強透視（近端放大、遠端急縮）。

### ⚠⚠ v3 踩到的取景衝突（提示詞自己打架）

我在威壓感那一段寫了「**雙翼張開撐滿畫面兩側**」「**佔滿整個畫面高度**」，
而硬規格是「**全身完整入框**」—— 兩句話直接衝突，結果 v3 三張的翼尖爪尖全被裁掉
（量出來 `v3_unsealed` 的**左邊緣有 86% 是實體**）。
⇒ **威壓感與完整入框要一起寫死**：「鏡頭往後退一點，牠可以小一點沒關係，
**完整比大更重要**；四周各留 5~8% 空白；每一個端點都不可以碰到邊緣」。
⚠ 驗收有客觀量法：量四條邊上「alpha>32」的像素比例，**超過 5% 就是被裁到了**。

### ⚠⚠ 收圖的限制（chatgpt.com）

程式觸發的 `a.click()` 下載**完全不作動**（內建瀏覽器也一樣），
**只有真的滑鼠點擊會過，而真點擊需要 Chrome 是系統前景視窗**。
Chrome 一退到背景，`computer.left_click` 就完全打不進頁面（可以用一層
透明 div 記 click 數來驗）。圖留在對話裡跑不掉，等 Chrome 回前景再一次收。
收法：頁面內把多張 fetch 成 bitmap → 全解析度疊成一張長圖 → 一個 `<a download>`
蓋滿畫面 → 按一次 → PIL 切開。無損，而且把 N 次下載壓成 1 次。
