# 苦笑系（`mon_rictus_*`）— 美術規格

> Ray（2026-09-08）：「下一批換個風格，**以痛苦扭曲或誇張笑容為主**，心理恐怖」

`rictus` ＝**僵住的咧嘴**，同時涵蓋「痛苦的抽搐」與「笑得不對勁」——正是這一批的兩極。

## ⚠⚠⚠ 這一族與聖遺物系（`_relic_spec.md`）**故意相反**

| | 聖遺物系 `mon_relic_*` | 苦笑系 `mon_rictus_*` |
|---|---|---|
| 主體 | **器物**取代頭或軀幹 | **臉與身體本身的變形** |
| 臉 | **完全沒有臉**（身分被器物蓋住） | **臉就是主角**，一定看得到 |
| 道具 | 蠟燭／經頁／布幡／鏈，堆得很滿 | **道具要少**，畫面留給身體 |
| 剪影 | 一團密集的直立塊體 | **每一隻都要有自己的體姿**（扭、折、拉長、蜷） |

⚠ **不要把上一族的布幡與蠟燭堆搬過來** —— 那是 relic 的簽名。這一批「換個風格」的
落點就在這裡：**東西少、身體多**。

## ⚠⚠⚠ 鐵則：**要嘛不要有眼，要嘛不要有嘴**（Ray 追加，2026-09-08）

> Ray 原話：「要嘛不要有眼，要嘛不要有嘴」

一張臉上**眼與嘴不可以同時齊全**，**逐隻二選一**：

| 選哪一邊 | 缺的那半怎麼處理 | 剩的那半要做到極致 |
|---|---|---|
| **無眼** | **深的空洞眼窩**（見下面鐵則一之二） | **嘴** —— 誇張到不該有的笑，或痛苦扭曲的巨大張口 |
| **無嘴** | 嘴被縫死／被封成一條凸起的疤／整片皮蓋過去根本沒有開口／被自己的手壓死 | **眼** —— 睜到極大，**但裡面是空的** |

- **為什麼**：五官齊全就只是一張醜臉；**缺一半才讀得出「這東西不對」**。
  表情只剩一個器官在演，缺的那一半正是恐怖的來源。
- ⚠⚠⚠ **每一則提示詞都要明寫這一隻是哪一種**（同「四鐵則逐次寫」那條的理由：
  中間隔幾張沒寫，模型就會把五官補回去）。
### ⚠⚠⚠ 鐵則一之二：**這一族的眼睛一律是「空洞」**（Ray，2026-09-08）

> Ray：「眼睛應該要**空洞**，比較有恐怖感」

**兩半各有各的空洞畫法，但語意是同一個：那裡沒有人。**

| | 怎麼畫 |
|---|---|
| **無眼那六隻** | 眼睛的位置是**深的空洞眼窩** —— 沒有眼球、沒有眼瞼、沒有睫毛，洞內只有暗，**看不到底**。⚠ 不是挖掉的傷口、不流血：那裡本來就沒有長過眼睛。 |
| **無嘴那四隻** | 眼睛**在**，但**是空的** —— 睜到極大、眼白大面積露出、**瞳孔極小或根本沒有瞳孔**、完全不聚焦、**一點高光都不要**。看著你，但後面沒有東西在看。 |

- ⚠⚠⚠ **這條推翻了先前「無眼的畫法要逐隻不同」**（縫死／布帶蓋住／整片平滑的皮／
  被下一層臉蓋住）。那些全部是**「遮起來」** —— 遮起來只是你看不到，
  **空洞是「本來就沒有東西」**。恐怖差在這裡，所以不換花樣，**全部用空洞**。
  · 連帶：`inhale` 的 X 縫線、`puppet` 的灰布帶、`seam` 的平滑皮**都改成空洞眼窩**。
- ⚠⚠ **無嘴那半也要改**：先前寫的「瞪到眼眶變形、眼白佈滿血絲、眼球前凸」是
  **卡通式的痛苦**，讀起來是在用力，不是空的。血絲與暴突拿掉，改成**大而空**。
- ⚠ **`mon_rictus_hooked` 的例外也一併收掉**：牠原本靠「眼睛沒在笑」，
  而空洞正是那個效果的極致版 —— 重畫成無眼（空洞眼窩）之後，全族十隻規則一致。
- ⚠⚠ **鼻子不算在這條規矩裡**（Ray 補述：「鼻子根本不重要，沒有感情」）——
  它演不出東西，**有沒有都不影響**，不必特地拿掉、也不必特地畫。
  · **例外：把鼻子本身變成變異**（例如整張臉只剩一個誇張的大鼻子）—— 那時它才是主角。
    那是刻意挑的例外，不是預設。
  · ⚠ 這條也**不是「不要有完整五官」**（少一隻耳、沒鼻子也算）—— 那個讀法太寬，
    已由 Ray 更正作廢。**就是眼／嘴二選一。**
- ⚠⚠ **`mon_rictus_hooked`（鉤笑者）的舊版眼與嘴齊全** —— 它靠的是「上下半張臉
  不一致」（嘴在笑、眼沒在笑）。這條規矩是那個效果的**更強版本**，
  空洞（鐵則一之二）又更強一階，所以**牠已改成無眼重跑**，不再是例外。
  舊版留在 `resources/enemy/mon_rictus_hooked.webp`（線稿與上色仍是畫風參考）。

## ⚠⚠⚠ 鐵則二：**要掉 SAN —— 有份量、有壓迫感、有攻擊性、強透視**（Ray，2026-09-08）

> Ray：「怪的設計要讓人掉 san 值，但**怪不要長得太削瘦單薄**」
>       「而且要有**壓迫感跟攻擊性**」「最好還要**強透視**」

第一批 Gemini 原形（裂笑）被這一條打回：牠**太瘦、站得太乖** —— 雙手在身前交握、
正面平視、全身等距。臉做對了，但整隻讀起來是「一個怪人」，不是「你完了」。

四件事，**每一則提示詞都要帶**：

| | 要什麼 | ⚠ 不要什麼 |
|---|---|---|
| **體格** | **有份量、有體積** —— 寬肩、厚胸廓、粗壯的前臂與大腿、脖子有厚度；裹布底下是**填滿的**身體 | **不要削瘦單薄**、不要骷髏架、不要竹竿 |
| **壓迫感** | 牠**比觀者大**：**低視角**（相機在牠腰部以下往上看），頭與上半身**壓向鏡頭**、頂到畫框上緣 | 不要平視、不要整隻縮在畫面中央 |
| **攻擊性** | **正在朝觀者逼近／撲上來**：前身壓低、重心前傾、手或上半身**伸向鏡頭**、張口 | 不要站著等你、不要雙手交握這種乖巧姿勢 |
| **強透視** | 靠近鏡頭的部位（伸出的手、前傾的頭、下顎）**明顯放大**，遠端急速縮小 —— 廣角鏡的感覺 | 不要等距的側視圖鑑照 |

- ⚠⚠ **「解剖正確」不等於「瘦」**：那條要的是骨突與關節長對位置，
  不是把肉削光。**肌肉與脂肪都要畫出來**，扭曲才有東西可扭。
- ⚠⚠ **強透視不可以把臉擋掉**：這一族**臉是主角**（見下表），伸出的手要繞開臉，
  或壓在畫面下緣。臉讀不到，前面那條鐵則就白做了。
- ⚠ 這一條其實就是憲法 §5 怪那一節的「朝觀者攻擊的氣勢」——
  原本是 GPT 那一趟才加，**現在提前到原形就要有**。

## ⚠⚠⚠ 鐵則三：**人型靠「加東西」拉出多樣性，順便把體積做大**（Ray，2026-09-08）

> Ray：「人型可以用**衣裝**和**多肢／錯肢／接肢**、**物件**、**野獸融合**來增加多樣性」
>       「**體積也會比較大**」

純人型很快就會長得一樣（同 `_relic_spec.md` 學到的「剪影會趨同」）。五個加法，
**逐隻挑一到兩個**，不要每隻都全上：

| 加法 | 怎麼加 | 順便解決 |
|---|---|---|
| **衣裝** | 不只裹布 —— 厚重的長袍、法衣、殘破的斗篷、綁帶、皮革與甲片；**布本身就是體積** | 削瘦、單調 |
| **多肢** | 手臂／腿的**數量**多出來（一對、兩對），各自有自己的動作 | 體積、壓迫感 |
| **錯肢** | 肢體長在**不該長的地方**（背上、胸口、頸側、另一條腿的膝上） | 掉 SAN |
| **接肢** | 明顯是**別人的**肢體被接上來 —— 粗細、膚色、比例都不一樣，接縫處皮肉增生 | 掉 SAN、體積 |
| **野獸融合** | 局部換成獸的構造（蹄、獸腿的反關節、獸的肩胛與厚毛、角、獸的肋廓） | 體積、剪影多樣 |

- ⚠⚠ **這一條放寬了前面「道具要少」那一句**，但**分界沒有變**：
  · **聖遺物系** ＝ 器物**取代**頭或軀幹、**完全沒有臉**（身分被蓋掉）。
  · **苦笑系** ＝ **臉還在演**（那張笑／那雙眼是主角），物件、獸體、多餘的肢
    都是**加在牠身上的體積與變化**，不可以蓋掉臉。
  **判準一句話：臉一被蓋掉，那隻就變成 relic 了，就是畫錯家族。**
- ⚠ 加法要**逐隻不同**：十隻裡不要出現兩隻都是「多一對手臂」。
- ⚠ 加了體積之後**臉要跟著放大**（低視角＋強透視本來就會），
  不然臉會被那一堆東西擠成小小一顆。

## 這一族的文法

1. **兩極，各半**：
   · **誇張笑容** —— 嘴角咧到不該到的位置、太多牙、笑得太久。
     ⚠ **眼睛不要跟著笑**：眼睛要是**平靜、疲憊或空的** —— 恐怖來自**上下半張臉不一致**。
   · **痛苦扭曲** —— 關節反折、脊椎過度後彎、軀幹被擰轉、肢體節數過多。
     ⚠ **不要血、不要開放性傷口、不要內臟**：這是**心理**恐怖，痛苦來自**姿勢**不是傷害。
2. **人體要畫得解剖正確**（同 relic 那條）：肌肉、骨突、手指的關節都要對 ——
   **恐怖來自「它是對的，卻彎到不該彎的地方」**。畫成軟趴趴的橡皮人就只是醜。
3. **皮膚是骨白／蒼灰**，牙是暖白，牙齦與眼周是很淡的灰粉。**低彩度**。
4. **配色只允許一個重色**：暗紅（很少量，用在束帶、線、瞳孔），其餘一律灰階。
5. **不要臉部的可辨識身分**：不要畫成某個人；五官要通用、性別中性、成年體型。
6. 少量道具是可以的（線、鉤、束帶、薄面具片），但**必須為那個表情服務**，不是裝飾。

## 硬規格（同其餘敵人）

- 直式 **1024×1536**、**全身入框**、**背景完全透明（alpha PNG）**、無地面無影子。
- anime style／cel shading／clean lineart／**絕不要顆粒感、雜訊噪點、油畫質感**。
- 線稿分主副線、陰影 3~4 階硬邊、牙與指甲畫出厚度與斷面。
- 調性：DMC／惡魔城／The Last Faith／Blasphemous／Elden Ring／隻狼／Dark Souls。

## ⚠ 三條禁忌（每一則提示詞都要帶）

- **不要兒童或幼體**。
- **不要血、不要開放性傷口、不要內臟外露**。
- **不要裸露**：身體用貼身的灰白裹布或破舊的長衣覆蓋（布要貼著身體，才看得出扭曲）。

## ⚠⚠⚠ 這一批（Gemini 原形）踩到／學到的四件

**1. 「無嘴」比「無眼」難很多 —— 因為`慘叫`那兩個字會把嘴召喚出來。**
`痛結` 連跑三次都畫出巨口，第四次才成功。前三次的提示詞都寫了
「那聲**慘叫**全部堆在雙眼上」——**那句話本身就在下令畫一張張開的嘴**。
成功的三隻（絞身／反折／多節）都沒有出現任何發聲的字眼。
⇒ **寫「無嘴」的那幾隻，提示詞裡一個發聲的詞都不准出現**：
不要「慘叫」「嘶吼」「咆哮」「尖叫」「呻吟」，連「吸氣」都不要。
正面寫成 **「牠完全寂靜、發不出任何聲音 —— 這正是恐怖的來源」**。
⚠ 反過來「無眼」幾乎一次就過：模型很樂意把上半臉畫成平滑的皮或空眼窩。

**2. 「沒有」要寫成「那裡是什麼」，不能只寫「不要畫」。**
有效的寫法是**指定替代物**：「鼻子下面到下巴是一整片完全光滑、沒有任何開口的皮膚，
**像假人模特兒、像雞蛋殼**」。只寫「不要畫嘴」會被當成「嘴不要太明顯」。
同 §5「不要顆粒感沒有用，要指定改畫什麼」那條，是同一個道理。

**3. ⚠⚠ 在「峽谷野獸」那一串裡畫人型，會被整串的上下文帶成獸。**
`提笑傀儡` 變成長毛三頭獸、`吸氣者` 變成鬃毛野獸、`痛結` 兩次都是長角四足 ——
那一串的前 20 則全是毛、角、蹄、骨桿經幡，模稜兩可的地方一律往那邊漂。
⇒ **每一則都要有防獸的前言**（已寫成 `__HUMAN`）：
「這一族是**人型**不是野獸：不要毛／不要角／不要獸頭／不要尾巴／不要四足站姿／
不要骨桿與經幡。牠是一個**人**。」
⚠ **更好的作法是另開一串**（同 -733「底圖要與題材同類」的反面）——
這次沒換是為了保住已經調好的體格與視角基準；下一族開新串。

**4. ⚠ 不要拿「下載鈕的數量」當作「產了幾張圖」的計數器。**
Gemini 的對話是**虛擬捲動**的：捲到哪裡才 render 到哪裡，所以那個數字會隨捲動位置
自己長大（實測從 39 一路跳到 51，其實一張新圖都沒有）。
· **要判「還在生成嗎」看 `停止回覆` 這顆鈕在不在**（在＝還在跑，而且此時
  `傳送訊息` 那顆不存在，送出會失敗）。
· 要對「哪一張圖是哪一隻」，走 DOM 的 `user-query` / `model-response` 順序，
  不要靠捲動找 —— 捲動找必然對錯（這次就把 `痛結` 認成 `吸氣者`）。
· 驗收用**聯絡表**：把最後 N 張 blob 畫進一張 canvas 再看，一次看完九隻，
  比一張一張捲過去快得多也不會認錯。

## ⚠⚠⚠ 回收的正解：**合成一張聯絡表，只下載一次**（ver 2026-09-08，Ray 點破）

Chrome 對同一個站台**只放行第一次自動下載，之後全擋**（「是否允許自動下載多個
檔案？」那個權限提示，是瀏覽器本身的 UI，頁面內的程式點不到）。
我先前的結論是「請 Ray 去改權限」—— **那是錯的方向**。Ray 一句「你怎不用內建的
browser」點破：**問題不是下載被擋，是我在下載十次。**

**作法（十張只花一次下載額度）**：

```js
// 1) 把對話裡所有 blob 圖畫進一張大 canvas（逐格加檔名標籤）
const srcs=[...document.querySelectorAll('model-response')]
  .filter(n=>n.querySelector('img[src^="blob:"]'))
  .map(n=>n.querySelector('img[src^="blob:"]').src);
//    …drawImage 進 5×2 的格子，每格 848×1300…
// 2) 做一個「真的看得到」的下載連結
const a=document.createElement('a');
a.href=c.toDataURL('image/jpeg',0.9); a.download='sheet.jpg';
a.style.cssText='position:fixed;left:100px;top:100px;width:400px;height:200px;z-index:2147483647;…';
document.body.appendChild(a);
// 3) ⚠ 用「真的滑鼠點擊」（computer.left_click）點它 —— 不是派送事件
```
- ⚠⚠ **一定要真實點擊**：`a.click()` 與派送出來的 MouseEvent 沒有使用者手勢，
  照樣被當成自動下載。真實點擊有手勢，第一次就過。
- ⚠ 連結要**畫得大、看得到**（不要 1×1 隱形元素）：要真的點得到它。
- **下載回來再用 PIL 切開**（每格 848×1300、標籤佔上緣 46px），
  一次拿到十張單圖，正好餵下一階段。
- ⚠ 副帶好處：聯絡表本身就是**驗收用的並排圖** —— 剪影趨同、規則違例
  （例如絞身者又長出嘴）一眼就看得出來，比一張一張捲過去快得多。

⚠⚠ **「內建 browser」不能拿來救這件事**：它是另一個瀏覽器，**沒有 Ray 的 Google
登入**，進不去那個 Gemini 對話。要換過去得先在那邊登入一次（Ray 未定）。

⚠⚠⚠ **正確的偵測法：看 `naturalWidth`，不要看 `src`。**
```js

```
