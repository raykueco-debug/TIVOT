## 三、⚠⚠ 錯格重影改成**兩層疊**：青藍重影當後景（Ray 定案，ver -1630）

> Ray：「用青藍色那張當後景層，零成本」「我讓程式把那張圖透明度調低放後景就好」

| 檔 | 角色 |
|---|---|
| `mon_gravekeeper_offset_body.webp` | **前景**：實體（骨白灰石），畫在上面 |
| `mon_gravekeeper_offset_soul.webp` | **後景**：青藍重影，壓低透明度畫在下面 |
| `mon_gravekeeper_offset.webp` | **退路**：合成版（重影烘在圖裡）。還沒接兩層之前用它，不會開天窗 |

**兩個檔已經對好位了** —— 同一張畫布 **1853 × 1858**，兩張都是那個尺寸。
⇒ **程式端只要把兩張畫在完全相同的 rect 上就好，不要自己算位移。**
（魂已經烘進去的錯位：dx **583 px**、dy **90 px** ＝ 本體外框的 0.60 / 0.06。）

| | |
|---|---|
| 圖層順序 | **魂在下、實體在上** —— 實體蓋住魂的邊緣一點點，魂再怎麼動都不會被裁 |
| 魂的混合模式 | **`screen`（或 `lighten`）**，不透明度約 **0.6** |

⚠⚠⚠ **不要用單純的 alpha 疊**：戰鬥背景是暗的，60% 的純 alpha 會把魂壓成灰糊、
線稿整個消失 —— **那正是舊圖壞掉的方式**（舊圖那一半實測半透明 34,064 px、
中位 alpha 217，疊在暗背景上是 RGB(139,137,137) 的一團灰白）。
實測三種並排：100% 不透明 ✔／60% 純 alpha ✘ 糊掉／**60% screen ✔ 保住線稿與對比**。

⚠ 加一點極慢的漂移會更好（畫面寬的 ±1.5%、週期 4~6 秒 ＋ 不透明度 0.55~0.68 明滅）——
錯位量已經烘在圖裡了，動畫只是讓它「跟不上」，不是讓它跑開。**不加也成立。**

⚠ 去背驗過：兩張的四角 alpha 全 0、近白比例 0.05% / 0.02%。

## 五、美術端的紀錄（不是程式端要做的事）

- 有效的措辭是 **「請直接修改我上傳的這一張圖，不要重新繪製一張」** ——
  框成「重畫」它就會去創作（跑掉兩版才找到）。同 §5 講 alpha 那一條的框法。
- **明寫失敗長什麼樣最有效**：「⚠ 不要挺胸直立、不要雙腳站姿、不要把前肢當成手舉起來」
  寫了這一句，牠才從人形站姿轉回四足伏踞。
- ⚠⚠ **平坦區雜點那個指標只能在同一種畫法之間比**：重繪版量到 15.98、原稿 13.18，
  但 200% 裁切一看是原稿糊成一團、新版乾乾淨淨 —— 新版**整張都是線稿**，
  連最平坦的三成區塊裡都有線，那個指標量到的是**線密度**不是雜訊。**一律以眼睛為準。**
- ⚠⚠ **補白改成「把畫布撐大」，不再縮小內容**（`tools/mon_pad.py`，ver -1630 改）：
  cel 圖是硬邊，0.86 倍縮放會在邊上振鈴 —— 實測 LANCZOS 9.05／BOX 8.77／BICUBIC 8.01，
  全部比原圖的 6.87 還髒；BILINEAR 6.73 是靠糊掉換的，而「模糊」正是這次要修的東西。
