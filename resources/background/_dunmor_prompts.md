## 共通段（每一則）

```
【共通規格 — 每一則都適用】
・畫一張遊戲背景：橫式 3:2（1536×1024）、平視鏡頭、畫面中央留空給之後疊上去的人物立繪（主要景物擺在左右兩側），畫面下面四成之後會被 UI 蓋住，所以重點放在上半。
・場景：鐵器時代古凱爾特丘堡的廢城。乾砌石牆（不用灰漿、扁石一層層疊、縫隙塞小石）、圓形石基座配茅草錐頂的圓屋、刻三曲紋與螺旋的立石、刻歐甘刻痕的界石、木柵與木棧、格紋羊毛布、鐵鍋與陶罐、青銅器。⛔ 不要羅馬拱券、不要哥德尖拱、不要城堡塔樓、不要任何東方元素、不要任何文字或符號招牌。
・破敗程度：不是千年廢墟，是幾天前剛被毀。倒塌石牆的斷口是新的、石面乾淨，沒有青苔、沒有藤蔓、沒有風化；斷掉的木柱與木椽露出新鮮的木色；茅草還是黃的，燒黑的地方還在冒一縷細煙。
・不久前還有人：生活的東西都留在原位，只是主人不在了 —— 每張放一到兩件（翻倒的陶罐、還掛在火上的鐵鍋、晾了一半的格紋布、地上的木碗與麵包、門邊的木桶與掃帚、繫在樁上的斷韁繩、很深的車轍）。⛔⛔ 畫面裡絕對不准出現任何人、任何屍體、任何動物、任何旗幟。這是一座無人的城。
・天空與光：整片天空是紫紅到絳紅的漸層（不是橘色的夕陽），雲層低而厚、帶暗紫，雲要畫成有形狀的塊；環境光偏紅、陰影偏紫藍；石頭是冷灰色帶一點紅光。光從畫面左邊來（畫面外的西邊），影子往右拖。⛔ 不要畫太陽、不要畫月亮。
・畫風：日式動漫背景美術，anime style, cel shading, clean lineart —— 所有輪廓有明確的深色描邊、明暗只有 2~3 階硬邊色塊、彩度偏高、天空與雲畫成有形狀的塊、草葉與樹葉畫成成團的塊狀輪廓。⛔ 絕不要顆粒感、不要雜訊噪點、不要油畫質感、不要散落的亮點閃粉、不要景深模糊、不要鏡頭光暈、不要照片級紋理、不要 3D 渲染感。
・出口：下面會說這一格有哪幾個方向可以走，畫面上就要有剛好那幾條真的走得過去的路（正前方＝畫面深處的路；左／右＝畫面兩側的缺口、坡道或門洞）。沒有列出的方向要畫成走不過去（完整的牆、壕溝、密林、斷崖），不要多畫任何一條看起來能走的路。
```

## 逐格

### causeway
```
【這一格：堤道】出口：只有正前方一條。
一條石砌堤道從畫面下緣正中出發，穿過沼地與外壕，直直伸向畫面深處；盡頭是丘堡的乾砌石壘與南壘門的門道（遠景，看得出門道的楣石塌了下來）。堤道兩側是積水的沼地與成團的蘆葦叢，水面映著紫紅色的天。堤道路面本身就是中央的留空，景物擺兩側：左側一根斷掉的木界樁繫著一截斷韁繩，右側一輛翻倒的手推車與滾落的陶罐。剛被破壞：堤道邊緣幾塊剛崩落、斷口乾淨的石頭；遠處丘堡裡有兩三縷細煙升起。
```

### southgate
```
【這一格：南壘門】出口：左邊一條、右邊一條（沿著壕溝的土坡道）。正前方走不過去。
兩道厚重的乾砌石壘夾出的門道正對鏡頭；門道上方那塊巨大的楣石塌了下來，斜卡在門道裡，把正前方整個堵死，門柱與楣石的斷口新鮮乾淨。左右兩側沿著壕溝各有一條被踏出來的土坡道往畫面兩側外延伸出去。門邊倒著被撞破的木柵門、一支斷矛、一個木桶。從塌落楣石上方的縫隙看得到裡面圓屋燒黑的茅頂在冒細煙。中央留空是門道前那片踏平的泥地。
```

### ditchW
```
【這一格：西壕】出口：正前方一條斜坡往上進城，右邊一條回壘門。左邊走不過去。
站在環壕的底部：兩側是高高的壕壁（乾砌石壘與土坡），壕底長著矮草與積水。正前方一條斜斜往上的窄坡道通到壕頂，坡頂的壘牆缺口透出紫紅色的天；右側壕壁上有一道缺口與踏出來的坡道。左側是完整無缺的壕壁，沒有路。壕底：一只翻倒的木水桶、一塊掉落的格紋布，壕壁上有幾塊剛崩落還乾淨的石頭。中央留空是壕底那條泥路。
```

### oghamrow
```
【這一格：歐甘石列】出口：只有右邊一條。正前方是盡頭。
一排六到八塊高瘦的立石沿著畫面左側往深處排開，每塊石頭的稜邊刻著歐甘刻痕（一組一組的短橫線與斜線沿著稜邊排，不是文字）；最近的一塊被推倒、斷成兩截，斷口新鮮。正前方立石列的盡頭是壘牆的內側石壁，走不過去。右側一條被踏平的小路穿過石牆缺口通往裡面的廣場（缺口裡看得到一座石臼）。地上：一個木碗與半塊麵包。中央留空是立石列旁邊那片踏平的草地。
```

### gatecourt
```
【這一格：門內廣場】出口：正前方一條、左邊一條、右邊一條，三個方向都能走。
一片踏平的泥土廣場，車轍很深，廣場中央地面留空。正前方一條鋪石的主街往深處通進圓屋群之間；左邊石牆一道缺口通往一排立石；右邊一條路通到一座架高穀倉的遺址（只剩四根石柱撐著半塌的木平台）。廣場上：一座石臼與翻倒的木杵、一輛少了一個輪子的雙輪車、一堆剛倒下的乾砌石牆（石頭乾淨）。遠處圓屋的茅頂冒著細煙。
```

### mainstreet
```
【這一格：石板主街】出口：正前方一條、右邊一條。左邊走不過去。
鋪著不規則石板的主街直直往畫面深處走，兩側是倒塌的圓屋：乾砌石圈與塌下來的茅草錐頂（茅草還是黃的、木椽新鮮）。右側兩座圓屋之間有一條巷口，巷口深處透出鍛爐的暗紅光。左側是連續的圓屋石牆與塌牆，堵住沒有路。正前方遠處看得到路口立著一根石柱。街上：一個還掛在三腳鐵架上的鐵鍋、翻倒的陶罐、一條晾在繩上被風吹起的格紋布。中央留空是街面。
```

### marketcross
```
【這一格：市集十字】出口：只有左邊一條。正前方被倒塌的牆堵死，右邊走不過去。
路口中央偏右立著一根高高的石柱，柱身刻滿三曲紋與螺旋，柱頂是一顆石球。石柱後方（正前方）是一整面剛倒下的乾砌石牆與塌落的茅草屋頂，把往前的路完全封死，石頭斷口新鮮乾淨。左側一條路在兩座圓屋之間往畫面左邊外延伸出去。右側是完整的圓屋石牆，沒有路。路口地上：翻倒的市集木攤、散落的陶罐與蘋果、一塊格紋布。中央留空是石柱前的路面。
```

### boarstone
```
【這一格：野豬石】出口：正前方一條、左邊一條、右邊一條，三岔路口。
三岔路口正中偏左立著一尊石雕野豬（粗獷的鐵器時代風格，背上的鬃毛雕成一排石脊，站在一塊石座上），石座上有新鮮的鑿痕與缺角。正前方一條路通往遠處內壘的巨大石門框（門楣看得到一圈頭像浮雕）；左邊一條窄巷（巷牆上嵌著陶片）；右邊一條路通往市集方向。地上：一個木桶與一把掃帚倒在路邊、深深的車轍、一只翻倒的陶罐。中央留空是路口的地面。
```

### innergate
```
【這一格：內壘門】出口：正前方一條、左邊一條。右邊走不過去。
內壘的巨大乾砌石門框正對鏡頭：門楣是一整塊長石，門楣上刻著一圈一圈的人頭像浮雕；木門被撞開，一扇歪掛在門軸上、門閂斷了露出新鮮木色。透過門洞看得到裡面往深處的路與一座大圓屋的影子和樹影。左側門框旁邊一道往下的土坡道通到內壕。右側是完整的乾砌石壘，沒有路。門前：翻倒的鐵火盆與散落的木柴，還冒著一縷煙；一個木桶。中央留空是門洞前的鋪石地。
```

### druidhouse
```
【這一格：德魯伊居所】出口：只有左邊一條。正前方是屋子本身，走不過去。
一座比其他圓屋大得多的圓屋佔滿畫面深處正中：門口兩根高木柱刻著粗獷的人頭像，茅草錐頂燒掉一半還在冒煙、木椽露出新鮮木色；門洞開著，門內看得到掛在梁上的槲寄生束、鋪在地上的獸骨與獸皮、一盞還亮著的油燈。左側一條小路穿過矮石牆通往一片古橡樹林（看得到粗大的樹幹與成團的樹冠）。右側是屋牆與密林，沒有路。門前：一只翻倒的青銅碗、灑出來的穀物、一支插在地上的木杖。中央留空是門前的空地。
```

### oakgrove
```
【這一格：橡樹林（休息處）】出口：正前方一條、左邊一條、右邊一條。
古橡樹圍成的一片空地：樹幹粗大、樹皮的皺褶用乾淨的描邊畫，樹冠畫成成團的塊狀葉。樹枝上掛著鐵環、小鈴鐺與褪色的布條隨風飄。正前方兩棵最大的橡樹之間是一條往深處聖林的小徑；左邊與右邊各一條通道穿過樹叢。空地中央留空：踏平的草地，中央一小圈石頭圍著的火堆餘燼還冒著一縷煙。地上：一件掛在低枝上的格紋斗篷、一個木杯。這一格要安靜、可以休息的氣氛，光從樹縫間斜斜灑下來。
```

### nemeton
```
【這一格：聖林祭場（休息處）】出口：正前方一條、右邊一條。左邊走不過去。
聖林中央的圓形空地，一圈高木柱圍著（柱頂刻獸首與螺旋），空地中央一塊長條的平石祭石。正前方兩根木柱之間一條石階小路往上通向遠處山頂的祭壇（三面立石的剪影襯著紫紅色的天）；右側木柱之間一道缺口通往一條岩壁窄廊。左側是密不透風的樹牆，沒有路。平石上：一把青銅鐮刀、一束槲寄生、一碗灑了一半的牛奶。中央留空是平石前的草地。安靜而肅穆。
```

### altar
```
【這一格：祭壇（終點）】出口：沒有。三面都走不過去，這是盡頭。
山頂的石祭壇正對鏡頭：一塊巨大的平石祭壇，左、右、後三面各一塊高聳的立石圍著，立石上刻著三曲紋與螺旋。祭壇後方立石之間只有懸崖與紫紅色的天空，濃霧從崖下湧上來繞著祭壇的底部。祭壇上：一個倒著的青銅大釜、一把儀式用的短劍、幾根還在燃燒的蠟燭。畫面中央祭壇前的鋪石留空。這是整座城最莊嚴、最有壓迫感的一張，天空佔畫面上半的大部分。
```

### wellsq
```
【這一格：聖井廣場（休息處）】出口：沒有新的路，來路在畫面左邊。
一個被乾砌石牆與圓屋牆三面圍起來的小廣場，安靜的死角。廣場盡頭正中偏右一座圓形石砌聖井，井口上方一根橫木架吊著木桶；井邊一棵歪脖子的山楂樹上掛滿褪色的布條隨風飄；井口看得到清澈的井水映著紫紅色的天。畫面左緣有一道石牆缺口是走進來的路，其餘三面是完整的牆，沒有任何其他出口。地上：一只剛打上來還滿著水的木桶、一雙木屐、一條晾著的格紋布。中央留空是井前的鋪石地。安靜、可以休息的氣氛。
```
