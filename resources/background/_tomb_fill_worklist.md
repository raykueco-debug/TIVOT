## 一、規格（每一張都一樣）

| | |
|---|---|
| 尺寸 | 與既有古墓背景同規格（`resources/background/tomb/` 那一批） |
| 格式 | **WebP**（交 PNG 也可以，程式端會轉並把原檔收進 `_originals/`） |
| 檔名 | **照表上那一欄，全小寫**（ver -1554 的全庫規約） |
| 時段差分 | **不用**。古墓全部 `noTime:true`（地下不吃時段）—— **一格一張** |
| 畫風 | §5 四鐵則：**anime style／cel shading／clean lineart／絕不要顆粒感** |
| 調性 | 照既有那 34 張（哥德石造、冷灰＋燭火暖點、濕氣與苔痕） |

⚠⚠⚠ **「畫得出幾條路」是硬規格**（憲法 §6.5.4.4）：
表上的「出口」那一欄是**資料上真的有幾條路**。
· 1 條 ＝ **盡頭**（只有你進來的那個方向，其餘三面是實心牆／塌方）
· 2 條 ＝ 直廊或轉角
· 3~4 條 ＝ **岔口**，每一個出口都要是**真通道**（石造門框或塌開的缺口、
  地板石板連續延伸進去、洞內暗下去）—— **壁龕假路不算**。
**多畫一條是說謊（玩家會往那裡走）；少畫一條只是「那邊沒路」，可以接受。**

## ⚠⚠⚠ 五、程式端要接：小地圖改成**三層**

1. **`script/town.js` 的 `map` 要能吃三張** —— 一層一張圖 ＋ 一組 spots，
   依玩家**現在站在哪一格**決定顯示哪一層。三層的節點清單就是那三個
   `_spots_tomb_l*.json` 的 key（21／33／7）。
   ⚠ **三張的長寬不一樣**（l1/l2 1536×1024、l3 700×830）—— `spots` 是**比例**，
     所以照抄就好；但版面若寫死了 3:2，第三層會被拉扁，要改成依圖自己的比例擺。
2. **spots 一律照抄那三個 JSON** —— 一個數字都不要用眼睛估（-1145：圖上那顆點與
   那份數字是同一次算出來的）。舊的 34 筆全部作廢。
3. ⚠ **還沒切三層之前照舊能跑**：`map_tomb.webp`（61 格全圖）與 `_spots_tomb.json` 留著。
   但那張是**同名覆蓋** ⇒ 若要繼續用它，`map.img` 必須掛 `?v=2`（§5 的 -650）。
   `map_tomb_l*.webp` 是新檔名，不必掛。
4. ⚠ 迷霧（`fogOn`）照舊逐格判 —— 換成三層之後每一層只畫自己那幾格，
   沒走到的照樣蓋霧，邏輯不變。
