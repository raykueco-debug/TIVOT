# 夏爾森林 Shinier Forest — 背景規格（ver -758）

夏爾村「野外」往上走進來的**野戰地圖**（森林）。節點與連線的唯一真相＝
設計圖（scratchpad 的 field_map_design.png，已交 Ray 過目）；
遊戲資料在 `script/town.js` 的 `TOWNS.shinier_forest`。

## 節點對照表（檔名前綴 `Forest_`，Day / Dusk / Night 三時段）

| 節點 | 檔名前綴 | 備註 |
|---|---|---|
| 森林入口 | `Forest_Entry_` | 村子邊緣，林道起點；復活點，氣氛可以安全些 |
| 林間空地 | `Forest_Glade_` | 主線戰①；北面要看得到**斷崖**擋路 |
| 獸巢 | `Forest_Nest_` | 支線戰（素材）；獸骨、抓痕、巢穴 |
| 淺灘 | `Forest_Shoal_` | 主線戰②；林中溪流淺水 |
| 河谷 | `Forest_Valley_` | 支線採集；藥草、莓果之類 |
| 舊獵道 | `Forest_Trail_` | 主線戰③；獵人走出來的舊徑，陷阱與標記 |
| 岩窟 | `Forest_Cave_` | 支線寶箱；淺洞穴 |
| 高地 | `Forest_Highland_` | 主線戰④；爬上來的坡頂，樹稀了 |
| 斷崖邊 | `Forest_Cliff_` | 無戰；崖頂沿線，看得到遺跡方向 |
| 遺跡入口 | —— | **不用畫**：直接用遺跡那批的 `Ruins_Entrance_Day/Night` |

共 9 個節點 × 3 時段 ＝ **27 張**（遺跡入口沿用既有）。

## 共用規格（每張都要）

- 橫式 3:2、平視圖、**中央留空給人物立繪（景物擺兩側）**。
- 與夏爾村同一片水土（`_shinier_spec.md` 的風土延伸到村外）：南美殖民期的
  鄉間、湖區林相 —— 闊葉林、蕨類、苔石、垂藤；獵村的痕跡（獵道標記、曬架、
  陷阱、獸骨）散見於各節點。
- 越往北（高地／斷崖）樹越稀、石越多，遠景漸漸看得到遺跡的輪廓。
- 產圖四鐵則（CLAUDE.md §5）：anime style／cel shading／clean lineart／
  **絕不要顆粒感**。
- 產圖順序照 §5：**GPT 先出第一張定風格，Gemini 拿那張當底圖跟進**；
  底圖用夏爾村同批（題材同類）。
