### 旅店（day 基底）
```
【這一格：旅店大廳（白天）】
一間西班牙風旅店的接待大廳，鏡頭從門口往裡看。木格梁天花板、地上是藍白與赭黃拼花的彩色瓷磚地板、白灰泥牆下半是藍白 azulejo 瓷磚護牆。**中央偏左一道深色木製接待櫃台**（檯面放一盞黃銅油燈、一本登記簿、一個小銅鈴），⚠ 櫃台**正上方那一塊牆面要留乾淨的白灰泥、不要掛任何東西**（之後要放按鈕）；櫃台後方牆上一排掛著黃銅鑰匙的小木格。櫃台前方放一張矮木桌與兩張藤編扶手椅、一盆小橙樹。**畫面右側三分之一空出來：只畫一道往上的石階與樓上走廊的白牆與欄杆**（那一帶之後要放四扇門，所以牆面要平整、不要有窗或畫）。左後方一道馬蹄拱門通向內庭 patio，看得到噴泉與橙樹，正午的白光從拱門灑進來在瓷磚地上切出一塊硬邊亮塊。⛔ 不要人、不要文字。
```
### 酒吧（day 基底）
```
【這一格：酒吧（白天）】
一間西班牙風的老酒館（bodega）內部，鏡頭從門口往裡看。**中央偏左一道長吧台**：深色木身、白色大理石檯面，檯面上幾個陶壺、一疊小碟、一盞黃銅油燈（白天沒點）；吧台後方整面牆是**橫躺疊放的大木酒桶**（雪莉酒桶，桶頭寫著看不懂的粉筆記號）與木架上的酒瓶；天花板的木梁上**吊著幾隻整條的醃火腿與大蒜辮、乾辣椒串**。白灰泥牆下半是藍白 azulejo 護牆，地上是磨舊的赭色瓷磚。幾張高腳凳與兩張小圓桌配木椅。左側一扇木百葉窗半掩，**正午的硬光從百葉縫切成一道道亮條落在地上與吧台上**，室內其餘是暗而暖的褐色調。牆上掛一把舊吉他、一張鬥牛海報（沒有字、只有剪影）。**畫面右側三分之一只放牆面與一扇小窗**。⛔ 不要人、不要看得懂的文字。
```

### 貧民窟
```
【這一格：舊碼頭貧民窟】（這一格是盡頭：水岸走到底，沒有任何往前或往兩側的路）
聖索菲亞城舊街區後面、廢棄的舊石砌碼頭，現在變成了貧民窟。鏡頭沿著石造碼頭往水面看：左右兩側是**剝落到只剩磚與土黃石的舊倉庫**，被隔成一戶戶的住家 —— 破掉的木百葉窗、用木板釘補的門、鍛鐵陽台生鏽、藍白瓷磚碎了一半；**倉庫之間與碼頭邊上用漂流木、帆布與瓦楞鐵皮搭出一層層的違建棚屋**，一部分架在木樁上伸出水面；家家戶戶之間拉滿晾衣繩（褪色的布、補丁的衣服），碼頭邊有曬魚的木架、堆疊的破漁網、木桶與竹籃、一小堆炭火在煮東西冒著煙。地面是磨損的圓卵石與積水的坑。水面是渾濁的綠色，繫著幾艘漏水的小舢舨。**畫面深處、水的對岸，看得到富人區的白牆與那座彩瓷尖頂鐘塔**，形成對比。
**這裡的居民是「森住民」：深褐色皮膚、一頭白髮（老少都是白髮）的人**，穿著褪色的粗布衣。畫面裡放**三到四組、每組兩三個人**，散在**中景與遠景的兩側**（不要站在畫面正中央、不要靠近鏡頭、不要有人正對鏡頭），各自在做生活的事：坐在門口補漁網、提著水桶走過、小孩在棚屋間追跑、一個老人坐在木箱上曬太陽。⛔ 不要屍體、不要任何富人或士兵、不要看得懂的文字。
畫面中央的碼頭地面留空。光線與天空跟附圖一致：南歐正午的強烈硬光與鈷藍天空 —— 貧民窟不是靠陰天表現，是靠破敗與擁擠。
```
