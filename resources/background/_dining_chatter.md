# 餐飲街四店的路人語（ver -578，Ray 交辦）

⚠ 這只是**稿**，還沒接進 `script/town.js`——接的時候放進該節點的 `chatter`，
照 §6.5.4 的規矩：沒有立繪、名字欄是「路人」、點一下出一句再點一下收。
⚠ 口氣照 §6.5.4 的既有慣例（不用「」包起來、句子裡原有的引號保留）。

## 咖啡廳（蕾娜可能出現）

```
'今天的報紙寫著北方泊地的補給線又斷了。',
'這裡的豆子是南境來的，戰前一磅只要三分之一的價。',
'聽說教廷又在招募了，這次連文書職都要。',
'那位先生每天早上都坐同一個位子，從來不說話。',
'加了牛奶就喝不出苦味了——現在的牛奶也不好買呢。',
'永夜之後，能安靜坐著喝一杯就算奢侈了。',
```

## 餐廳（諾薇兒可能出現）

```
'今日的湯是甜菜根，配給的關係，這禮拜第三次了。',
'從前這裡的午市要排到街角，現在隨時都有位子。',
'廚房那邊在吵什麼？大概又是肉送不到吧。',
'那桌是市政廳的人，每次都點最貴的那道。',
'孩子第一次進餐廳，別把叉子拿反了。',
'吃完飯還是早點回家吧，天黑得越來越早了。',
```

## 甜品店（安雅可能出現）

```
'糖現在比銀還貴，這一份要價半天工錢呢。',
'櫥窗裡那個栗子塔，我看了三天了。',
'老闆娘說戰前的配方要用兩倍的奶油。',
'小心別把糖霜沾到袖子上——洗不掉的。',
'甜的東西吃了心情會好，母親以前是這麼說的。',
'排隊的人比麵包店還多，真的有那麼好吃嗎。',
```
