# 西湖村 Westlake — 村落地圖規格（Ray 交辦）

**索拉娜的故鄉。** 湖畔的自然風光村落，9 個場景 × 3 時段 = **27 張**。

| tavern | 半露天餐廳兼酒館 | `Westlake_Tavern_` |
| hotel | 旅店 | `Westlake_Hotel_` |

時段後綴：`Day` / `Dusk` / `Night`。

⚠ **明確不做**：教堂、行政廳、墓地、碼頭／渡口、公會。武器與雜貨**都是露天攤**，
不是店面；餐飲**不分類**，只有一家半露天的餐廳兼酒館。

## 共用規格（每張都要）

- 橫式 3:2、平視圖（玩家站在那一格看出去）、**中央留空給人物立繪（人擺兩側）**。
- 日式動漫 clean lineart、cel shading、**絕不要顆粒雜訊噪點、不要油畫質感**、
  不要浮水印、不要文字。
- **風土**：南美殖民期間的鄉間感 —— 夯土／灰泥牆、紅陶瓦屋頂、木廊柱、藤編與粗織布、
  曬在外面的染布，混著歐式的窗框與鐵件。湖畔的自然風光（水、蘆葦、林木、遠山）。
- **居民**：大多是**褐膚白髮**的同一族群，也有少數歐洲人；兩邊的穿著互相影響
  （歐式襯衫配當地織紋披肩、當地人穿歐式背心）。

## 三個時段

| | 光線 | 人 |
|---|---|---|
| `Day` | 明亮白天、陽光穿過雲隙 | **有人**：村民日常（洗曬、挑水、修補漁網、孩子跑過） |
| `Dusk` | 黃昏，暖橘金色斜光、長影、天空橙紫漸層 | **有人**：收工、趕牲口、點燈前的忙碌 |
| `Night` | 深藍紫夜空、屋內透暖光、油燈與提燈 | **一個人都沒有**（連背影剪影都不要） |

⚠ 夜景若畫到月亮**必為銀色滿月**（同北方泊地的鐵則）。
