# 一、⚠⚠⚠ 先讀：這一輪學到的四件事（**不讀會重犯**）

## 1. 收生成圖要掃 `img`，**不要掃 `main img`**

我整晚回報「還沒出圖」全是假的 —— ChatGPT 把生成圖掛在 `main` **之外**，
`document.querySelectorAll('main img')` 永遠是 0。正確：

```js
const g=[...document.querySelectorAll('img')].filter(i=>i.naturalWidth>=900);
const b=await (await fetch(g[g.length-1].src)).blob();
const a=document.createElement('a'); a.href=URL.createObjectURL(b);
a.download='gen_xxx.png'; document.body.appendChild(a); a.click(); a.remove();
```
⚠ 判「有沒有新圖」比對 **blob.size**（同一張重抓 size 一樣），不要看數量。

## 2. **同時最多四～五個生成分頁**

開到七個之後有兩個分頁 renderer 卡死（`Runtime.evaluate` 連續 45 秒逾時），
而卡住的分頁每次操作都要吃 45 秒，比省下的時間還多。超過就關掉幾個。

## 3. 一條串**只送一個提示詞**，不要連著丟四個

龍那一條我連丟四則（初版→加體積→留白→改正面），**只出一張就塞住**，
後面三則跑不出來。⇒ 要修就**關掉、開新串、一次把完整規格寫清楚**。

## 4. 上傳只能從**工作目錄底下**

`file_upload` 不吃 `~/Downloads` 的檔（權限）。要拿生成圖當底圖就先
`cp ~/Downloads/gen_x.png resources/_originals/<類>/`，再上傳那一份。

# 五、小地圖的做法（古城那張已完成，其餘兩座照抄）

**分工**：拓樸與座標是 **Ray 的設計**（他直接給 `_topology.pdf` 與 spots）／
幾何由**程式算**／畫法交給模型。

| 件 | 怎麼來 |
|---|---|
| **紙** | **合成**的：取舊紙的中位色（217,183,139）＋三層噪聲（低頻斑塊 σ7・中頻纖維 σ3・細粒 σ1.6，RGB 權重 1/0.93/0.80）＋ 高斯 0.5；四邊把原圖的**撕邊**用 5% 寬的羽化遮罩貼回去 |
| **圖示** | 跟模型要**貼紙表**（純白底、N 欄×M 列、每格一個符號），亮度鍵成 alpha（`(225-lum)*3`） |
| **線／墨點／草書名** | 程式畫。字型走 `tools/_font.py` 的 `cursive()` |

**手繪的線**（憲法 §5 ver -1437）：垂直方向走**平滑隨機漫步**
（`v=v*0.55+rnd*amp*0.6`，`amp=min(9, 3+L/230)`）＋ 逐段變粗細
（`LW*(0.60+0.7*sin(πt)±0.22)`）＋ 兩端各**出頭 6~18px**；轉角兩筆**交叉出頭**；
墨點是**不規則橢圓**（半徑 ×0.88~1.18）。

**版面**：畫布 **2400×2600（直式）**、`ICON_PX=52*K*1.35`、`NAME_PX=26*K*1.35`、
`DOT_R=7*K*1.2`、`LW=5*K`（`K=W/1536`）。古城的邊界 `ML.055/MR.145/MT.060/MB.045`。
⚠ 名字往右長 —— **最右那幾格要把名字排到墨點左邊**，否則出血。

⚠⚠⚠ **圖示不要從舊地圖上切**：舊圖是整張交給模型畫的，圖示沒有規矩地壓在墨點正上方
—— 37 個裡有 24 個會切到隔壁的**草書名字母**。放大 2 倍才看得出來，別再試。
