## 二、「不要太密太暗」是怎麼做到的

判準照東方泊地第二版定的那條：**縮到 1/8 還一眼讀得出是一座小鎮**。
提示詞裡把它寫成硬規格，而不是形容詞：

- 「這張會被縮到八分之一」「房子要少、街廓要大、街道要寬」「**寧可空也不要密**」
- 「整體要亮：淺色、高明度、低彩度」⛔ 深色調、⛔ 濃烈飽和色
- **大量留白**：鎮的周圍與中間要有大片單純色塊（草地、雪地、松林、農田、裸岩）
- **內容由大到小排**（碼頭 → 大廣場 → 主街 → 火車站與鐵軌 → 舊鎮區 → 新街區 →
  教堂 → 山脊 → 小河 → 外圍農田），模型才會先把大東西畫對

1/8 下讀得出來的東西：左緣的突堤與碼頭、淺色大廣場、橫貫的主街、
右側的月台頂棚與散開的鐵軌、穿鎮的小河、右上的綠色山脊、南側的農田方格。

## 三、去背：**要它畫純洋紅背景，不要要它給 alpha**

⚠ ChatGPT 與 Gemini 都**不會**給真的 alpha（Gemini 是畫一片灰白棋盤格）。
這一張改成在提示詞裡指定「**輪廓之外整片純洋紅 `#FF00FF`，鎮裡不准出現洋紅／粉紅／紫**」，
本機再鍵掉：

```python
m = min(R,B) - G                      # 洋紅度
alpha = 1 - clip((m-40)/(120-40),0,1)
# ① 只拔「從邊界 flood fill 連得到」的那一塊（城裡萬一有洋紅不會被誤挖）
# ② 沒連到邊界的透明像素一律補成不透明（＝§6.8 的「輪廓之內不准有洞」）
# ③ despill：部分鍵掉的邊緣把 R/B 壓到 G+18 以下
```

⇒ 比棋盤格那條**好鍵得多**，而且城裡本來就有的灰（花崗岩鋪面）不可能被誤判。
