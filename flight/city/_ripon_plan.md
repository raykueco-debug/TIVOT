## 一、它在哪、朝哪

- 飛行地圖座標 **(544, 595)**：聖索菲亞城（559, 562）南南西 36 格的**郊外**，地形整片平地、非禁航。
- **大門朝北北東＝朝聖索菲亞城**。⇒ **請把大門畫在圖的上緣**（程式端用 `planRot` 轉到正確方位，美術不必管角度）。
- 不是降落點（Ray），只是飛過去看得到的一座莊園。

## 二、畫什麼（照 `resources/background/sofia/sofiaout_*` 那 10 張的莊園）

1900 年前後西班牙南部的豪宅莊園（palacete），**從正上方往下看**：

| 區塊 | 俯視長相 |
|---|---|
| 主樓 | 兩層的大宅，**赤陶四坡瓦**屋頂（屋脊看得出來），屋頂是整座圖最大的一塊 |
| 右翼 | 馬車房＋拱門馬車道，赤陶瓦、比主樓小一號 |
| 前庭 | 主樓正面（朝大門那一側）一片**淺赭碎石地**，正中一座圓形噴泉（米白石） |
| 林蔭道 | 大門 → 前庭一條直道，兩側成排柏樹（深綠圓點） |
| 門房 | 大門內側一棟小屋（赤陶瓦） |
| 後露台 | 主樓背面一片米白石鋪面的露台，欄杆邊種盆栽 |
| 圍牆 | 米白乾砌石牆圍住整塊地，大門是一道缺口（鍛鐵門畫成一條細黑線就好） |
| 庭園 | 圍牆內零星棕櫚（放射狀葉叢）與花圃；圍牆外一小圈**橄欖樹**（銀綠色圓點，成排） |

⚠ **不要畫**：人、馬車、文字、地名、圖例、指北針、比例尺、陰影方向很強的長影子（光由引擎上）。
⚠ 模型會「越塞越多東西」（§5 第五條）：**這一張的目標是大色塊讀得出來，不是豐富**。

## 三、⚠⚠ 驗收判準：**縮到 1/8 還一眼讀得出是一座莊園**

這座莊園在飛行地圖上只有十幾個像素寬（比夏爾村還小）。原尺寸好看不算數 ——
縮到八分之一看：**紅瓦主樓＋米白圍牆框＋一片碎石前庭＋幾排深綠柏樹**，四樣都要分得出來。
（東方泊地第一版就是因為太密太深被退，見 `_eastport_plan.md` §三。）

## 四、技術規格（§6.8「貼地的平面圖」）

| 項 | 規格 |
|---|---|
| 尺寸／格式 | **1024×1024、RGBA、真的透明通道**（不是畫出來的灰白棋盤格） |
| 透明 | **只在圍牆輪廓之外**；輪廓之內 **0 個破洞**（§6.8 硬條件：內部透明會讓地形從洞裡透出來） |
| 四邊 | 圍牆離畫框四邊各留約 8% 的空白，不要貼邊 |
| 視角 | **正俯視**（正上方垂直往下），不要斜角、不要等角視 |
| 畫風 | anime style, cel shading, clean lineart，**絕不要顆粒感、不要雜訊噪點、不要油畫質感**（§5 四鐵則，每一則提示詞都要帶） |

## 五、⚠⚠ 交件單要附「來源整張的平均 V／S」（`_eastport_plan.md` §四的規矩）

程式端要照「成品目標」反解 `build_city.py` 的 `sat`／`val`，所以交件時附上這兩個數字：

```python
from PIL import Image; import numpy as np
h = np.asarray(Image.open(p).convert('RGB').convert('HSV')).astype(float)
print('來源 V %.3f  S %.3f' % (h[:,:,2].mean()/255, h[:,:,1].mean()/255))
```

## 六、程式端收到之後要做的（照 §6.7.5 的流程）

1. `flight/build_city.py` 補一個 JOB（`ripon`；`mx 544 / my 595`；`planW` 約 **220**；`planRot` 照大門朝北北東反推）。
   來源 1024 的正俯視 ⇒ **`maxdim:1024`**，`blkMin`／`blkSplit`／`blkCell` 照 §6.7.5 第 5.5 條一起放大。
2. 色調照「成品目標」反解（地中海郊外，暖一點，靠帝都那一組：成品 V ≈0.42／S ≈0.23），建完再量一次。
3. `SETTLEMENTS` 補一列（`t:'village'`、**不寫 `town`**、牆／瓦貼材沿用 geo 的 `flight_villagewall`／`flight_rooftile`，同夏爾村）。
4. **刪掉 `PLACES` 裡那一筆里朋莊園**（名牌改由 SETTLEMENTS 的 `n` 出，同一個地點不留兩份名牌）。
5. 試飛看遠／中／近三距離，確認沒有拉伸、城緣融進地貌。
