### 色調：目標**不是**城的基準
城的基準是「東方泊地 V 0.488 / S 0.271」（§6.7.5）。**這一張不一樣**：
它要與**谷底的棕石地**接得上 —— 那是 ver -1237 照 Ray「谷不要草地，用棕石地」
鋪的 `rock.col [134,108,78]`（地圖底色 V≈0.52 / S≈0.36）。
拿城的基準去瞄，貼上去會比它腳下的地淡一階、邊界整圈看得見。
⇒ 目標 **V≈0.50 / S≈0.26**。兩輪反推：
  `1.60/0.97` → 成品 0.529/0.184 → `2.25/0.92` → 成品 **0.515 / 0.248** ✔

### 尺寸：**船的兩倍**（ver -1245 Ray 定案）
> 「成了平貼的了，不用整那麼大，比船大1倍就好, 放在降落座標」

-1244 是「蓋滿整條谷」（planW 1760 ＝ 88×184 地圖格）——
攤成那麼一大片，它就不再是一個**地點**，而是一張鋪在地形上的貼紙。

**船的世界尺寸是量出來的**（不是估的）：量船在 2D 畫布上的非透明外框
**113×165 CSS px**，乘那一點的「每 CSS 像素幾個世界單位」
（`2z/BW × BW/W`，z 由 `drawShip` 寫死的螢幕 y=`VIEWH*0.76` 反推＝1.975）
⇒ **224 × 326 世界單位**。取寬的兩倍 ⇒ **planW 450**
（成品 450×943 世界單位 ＝ 22×47 地圖格）。

⚠ 順帶解決了 -1244 的解析度問題：733/450 = **1.63 texel/世界單位**（帝都 0.82）——
  骸骨、斷橋、石壇在飛行高度都讀得出來。

## 接線（`flight/index.html`）
`PLACES` 那一列補四個鍵；**沒有進 `SETTLEMENTS`**：
```
{x:985, y:858, name:'卡耶爾山谷', n:'卡耶爾山谷', type:'險地', town:'canyon',
  plan:'city/canyon_plan.webp', planX:962, planY:797, planW:1760, planRot:0},
```
· `planX/planY`（ver -1243 新增）＝圖自己的中心，與地點座標分開 ——
  那一點是**降落點與名牌**，不能為了貼圖去搬。
· 平面圖走 `cityPlates()`（ver -1243）：**只有取樣器那一端**吃 `PLACES`，
  道路／鐵路／程序聚落／整地／碼頭／路燈／量體／河口一概只看 `SETTLEMENTS`
  ⇒ 不會有一條公路通到死谷。
· **沒有 `podium`**：那道谷是 -1235~-1237 手刻的，整平就是把谷填掉。
