# _recycle — 回收區

**本專案唯一的「刪除」出口。** 任何 session（程式的、美術的）要拿掉或覆蓋掉任何檔案，
一律走 `tools/recycle.sh`，不准直接 `rm`，也不准用 `mv`／`cwebp` 就地蓋掉。

```sh
tools/recycle.sh -m "為什麼" <檔案或資料夾>...   # 回收
tools/recycle.sh --list                          # 看紀錄
tools/recycle.sh --restore _recycle/<路徑>       # 放回原位
```

## 規約

- 底線開頭 → **遊戲不載入**（同 `resources/_originals`、`_master`、`_unused`）。
- **保留原本的相對路徑**：`_recycle/resources/CI/x.png` 一看就知道它本來住哪，
  `--restore` 也才放得回去。
- **同名不覆蓋**：第二次回收同一個路徑會加時間戳。回收區本身不會弄丟東西。
- 每一筆記進 `RECYCLE_LOG.tsv`（時間 / 原路徑 / 回收路徑 / 理由），**這份紀錄入版控** ——
  所以「誰在哪一版拿掉了什麼」翻 git 就查得到。
- **回收區的內容只留在本機**（.gitignore），不進版控也不上靜態空間。
  它是「可回滾」不是「異地備份」；真要防硬碟壞掉要另外複製到雲端。

## 為什麼要有它

ver -695 之後 Ray 回報一張自己畫的諾薇兒 OBE 不見了。查下來：那張圖**從來沒進過版控**，
所以 git 也救不回來 —— 沒進版控的東西一旦被搬走或蓋掉就是真的沒了。
版控只保護「commit 過的」，回收區保護的是**還沒 commit 的那一段**，兩者不重疊。

⚠ 清空回收區是 **Ray 的決定**，不是任何 session 的。沒有人被授權清它。
