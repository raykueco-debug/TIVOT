# 西文（拉美中性）譯法定案

> 改譯文之前先讀這一份；新增定案就寫回來（只此一份）。專有名詞的正本是
> `reference/TIVOT_Glossary_ZH_EN_JA_ES.xlsx` 的 Español 欄，這裡只記**表上沒有的決定**。

## 市場與語域
- **拉美中性西語**（Ray 定案，10-02）。不用 vosotros（複數一律 ustedes）、避開西班牙限定用字
  （vale、coger、tío、chaval、ultramarinos、ayuntamiento…）；「zorra」在拉美是髒話，禁用。
- 四人語氣照 `flight/script/STYLE.md`；安雅短句但有禮，不要補成流暢複句。

## Ray 的決定
| 項目 | 定案 |
|---|---|
| 薇拉馮德 | **Velafonte**（義大利文，帆＋泉），四語統一；程式鍵 `verafond` 不動 |
| 璐娜團長 | 是 **Lunaria**（la comandante Lunaria） |
| 獸骸 | 只用「骸」＝ **cáscara(s)**（同表上 狼骸＝Cáscara de Lobo 那一族） |
| 諾薇兒對安雅 | 「我……只想當安雅而已！」事件**之前用 usted**（安雅小姐＝señorita Anya），**之後用 tú** |
